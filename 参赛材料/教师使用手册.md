## 一分钟版

1. 打开安装包，把 Mochi 拖进「应用程序」。第一次打开要**右键 → 打开**。
2. 第一次启动会问你：这台电脑是**教师办公电脑**还是**教室一体机**？选第一个。
3. 不用填密码、不用填 API key——**已经内置好了**。
4. 打开就能用。想让它干什么，**直接用大白话说**。

## 一、怎么安装

### macOS

1. 双击 Mochi-0.1.0-mac-arm64.dmg（**只适用 Apple 芯片的 Mac**；英特尔芯片的 Mac 装不了）。
2. 把 **Mochi** 拖进「应用程序」文件夹。
3. **第一次打开要按右键**：
   - 在「应用程序」里找到 Mochi → **右键（或按住 Control 点它）→ 打开** → 在弹窗里再点一次「打开」。
   - 为什么？因为这个安装包**没有做苹果的代码签名和公证**。直接双击会被系统拦住，那是正常的，不是病毒。
   - 之后就可以正常双击打开了。

### Windows

1. 双击 Mochi-Setup-0.1.0-win-x64.exe（适用 Windows 10 / 11 的 64 位版本）。
2. 屏幕可能弹出蓝色的 **SmartScreen** 提示，写着「未知发布者」：
   - 点 **「更多信息」** → 再点 **「仍要运行」**。
   - 同样是因为安装包**没有代码签名**，不是病毒。
3. 一路点「下一步」装完。

### ⚠️ 安装会比较慢

这个安装程序要往硬盘里写**很多个小文件**，如果电脑开着 Windows Defender 这类杀毒软件，它会一个一个地扫，安装可能要**十几分钟**。
**请不要中途关掉窗口**，让它跑完。安装界面如果看着像卡住了，再等一会儿。

## 二、第一次打开：选角色

第一次启动会弹出一个框：

- **标题**：设置 Mochi 本机角色
- **问的是**：这台设备用于教师办公电脑还是教室一体机？
- **三个按钮**：
  - **教师办公电脑** —— 老师本人用（**你自己装的话选这个**）
  - **教室一体机** —— 装在教室大屏上
  - **退出** —— 先不选

**选错了不要紧，也不用重装**：点屏幕最上面（Windows 是右下角）的 **Mochi 图标** → 点 **「切换本机角色：教室一体机」**（或教师办公电脑），确认后程序会重启一次。

**两边的数据是完全分开的**：教室端**看不到**教师端的密钥、记忆和聊天记录。

⚠️ 待核：菜单栏图标的样子和确切位置请在你的电脑上确认一次。

## 三、开箱即用：不用填任何密码

安装包里**已经内置了模型密钥**（一个负责聊天，一个负责看图）。所以你**不需要**去申请 API key、不需要填任何密码。

如果哪一天它提示「没有可用的模型」，那说明内置密钥出了问题，请联系作者——**不要自己去乱填**。

⚠️ 待核：如果作者重新出了包，请确认这一条是否仍然成立。

## 四、怎么连教室端

> 这一步只有**要把电脑接到教室里的大屏**时才需要做。平时自己办公用不着。

1. 点**侧边栏最下面**的 **「教室连接」**（如果显示的是「待设置身份」，也是它）。
2. 在 **「本机身份」** 这张卡里填：
   - **学校标识**（必填）
   - **班级**：教师端可以留空；**教室端必填**
3. 点 **「核对后创建身份」**（已经有身份时会显示 **「核对后保存身份」**）。
4. 填完后，**「附近设备」** 里会自动列出同一局域网里的设备（它每 3 秒刷新一次）。
5. 看到教室那台之后，先点 **「验证身份与指纹」** 核对一下，**再发起配对**。
6. 教室那台机器上会弹出确认，**由人在那边点同意**，配对才算完成。

**几句必须记牢的话：**

- **「发现」不等于「认识」。** 列表里出现的设备只是「附近有这么个东西」，**不等于已经授权**。
- 配对必须**两边都有人点**，机器不会自己连上。
- 教室端收到通知后，要**人在教室那台机器上点「我已看到」**，教师这边才看得到回执。
- 教室端**不能主动**去找老师配对，只有教师端能发起。

⚠️ 待核：跨 VLAN（不同网段）的校园网可能**发现不到**设备，这是已知限制。

## 五、它平时能帮你干什么

下面 8 件事，**你只要用大白话说出来就行**，不需要背任何「提示词」。

| # | 能干什么 | 你可以这样说 |
|---|---|---|
| 1 | **每天上课前看一遍情况**（谁在医务室、谁没返班、有没有未读消息） | 「给我看下今天情况。」 |
| 2 | **看某个学生现在在哪**（只报告系统里真实有的记录，查不到就直说查不到） | 「张明远现在在哪？」 |
| 3 | **跟进一个学生**（核对情况、整理要做的几件事、起草给家长或同事的话） | 「帮我看看三班王雨桐这几天的情况，我该做点什么？」 |
| 4 | **代学生登记去医务室 / 回宿舍**（登记完是「待审批」，需要你亲手点确认） | 「三班王雨桐不舒服，要去医务室，帮我登记。」 |
| 5 | **做课件**（真的 PPT 文件，能改某一页） | 「做一份勾股定理的课件，20 分钟，8 页，要有例题。」 |
| 6 | **备班会**（目标、大纲、讲稿、课件） | 「下周开一次关于手机管理的班会，帮我准备。」 |
| 7 | **找教学材料**（先找本机教材库，再找本机文件，最后才联网） | 「找一下高中生物『细胞呼吸』这一节，教材上在哪一页。」 |
| 8 | **做班级周报**（汇总一周情况，出表格和 Word） | 「做高一(1)班这周周报。」 |

> 表里出现的学生姓名（张明远、王雨桐）是**虚构的举例**，不是真实学生。

另外它还会**记住你的习惯**（比如你常带的班、你偏好的表达方式），下次不用重复说。

**几条它一定会守的规矩**（不是宣传，是写在它规则里的）：

- 查不到就说查不到，**不会编**。如果它说「系统里没有记录」，那是它真的没查到。
- **不会做医学诊断**，学生在医务室的事它只负责走流程和通知人。
- **不会替你做决定**。要发消息、要改正式记录、要删东西，它必须先问你，**说清楚要做什么**，等你点头。
- 涉及具体学生成绩**只做班级整体分析，不会指名道姓做负面评价**。

## 六、生成的文件放在哪

- 文件**真的存在你的电脑硬盘上**，不是「给你一段文字让你自己复制」。
- 生成完成后，Mochi 会在回复里给你**完整的文件路径**，照着路径去找就行。
- 一般放在 Mochi 自己的工作文件夹里，大致是：
  - 教师端：~/.mochi-home
  - 教室端：~/.mochi-classroom-home
  - （⚠️ 待核：这两个路径我是从程序代码里核出来的，**请你在自己电脑上实际生成一个文件、按路径找一次**，确认无误。）
- **目前程序里没有一个「打开文件」的按钮**，需要你自己用「访达」（Windows 是「文件资源管理器」）按路径去找。

## 七、它记住了什么？怎么查看、怎么清空

### 查看

- 直接问它：**「你都记了我什么？」** —— 它会把记下的每一条列出来，还会告诉你**它为什么知道这件事**（来源、时间）。
- 或者问：**「你还记得我……吗？」**

### 清空

- 说：**「把记忆全部清空。」**
- 它**必须先把要删的数量念给你听**（包括有几条是「免疫的」），你明确同意之后才会删。**它不会自己删。**

⚠️ 这条「清空」是**不可逆**的。删之前请想清楚。

## 八、怎么删除数据（如实说明）

| 想删什么 | 现在怎么做 |
|---|---|
| **长期记忆** | ✅ 有清空入口：跟它说「把记忆全部清空」，确认后执行 |
| **聊天记录 / 会话** | ❌ **程序里没有删除按钮**。需要手工去数据文件夹下面的 sessions 里删（⚠️ 待核：删之前请先备份，或让懂电脑的人帮你） |
| **教材库（课本检索）** | ❌ **没有删除入口**，要手工删数据目录。另外说明一下：**教材库不在安装包里**，是单独给你的 |
| **整个程序的数据（全部重置）** | ❌ 没有「恢复出厂」按钮。要手工删掉上面提到的整个文件夹 |
| **卸载程序本身** | Mac：把「应用程序」里的 Mochi 拖到废纸篓；Windows：在「控制面板 → 卸载程序」里卸载。⚠️ 说明：卸载**不一定**会删除上面那些数据文件夹 |

**一句话**：目前只有「记忆」有正经的清空入口，其它都得手工删文件夹。这是当前的短板，作者知道。

## 九、出问题了怎么办

**现在没有「一键导出日志」这个功能。** 所以请这样报问题：

1. **截图**：出错的那个画面，连边上的按钮一起截进去。
2. **说明你刚才做了什么**：出错**前一步**点了什么、输入了什么；出错**之后**你点了什么。
3. **把这两样发给作者**（微信/QQ 都行）。有现象、有步骤，问题基本就能定位。

**几个常见情况，可以先自己试：**

| 现象 | 怎么办 |
|---|---|
| 打开时系统说「来自身份不明的开发者」 | 见第一节：右键 → 打开 |
| Windows 蓝色提示 | 点「更多信息」 → 「仍要运行」 |
| 它说连不上校园系统 | 检查这台电脑有没有连上校园网；还是不行就找作者（**这是已知问题**：新装的电脑默认可能连的是本机地址） |
| 它说没有可用的模型 / 一直转圈 | 等一下再试一次；连续两次不行就找作者 |
| 生成 PPT 或 Word 时报错说找不到导出引擎 | 这台电脑没装 LibreOffice。找作者，或用 WPS/Office 打开生成的文件后自己另存 PDF |
| 表格里有些公式算出 #NAME? | 它**明确不支持**几个函数（VLOOKUP、SUMIFS、TEXT、DATE 等）。它不会瞎给一个数，会点名告诉你哪个不支持——请改用别的算法或手工算这两个格 |
| 教室端收不到通知 | 确认两边在**同一个校园网**、配对成功、班级填对了 |

## 十、已知限制（先说清楚，免得你踩坑）

1. **安装包没有做签名**：Mac 要右键打开，Windows 要过 SmartScreen。这是正常的。
2. **教室功能还没在学校真机、真网络上验收过**。跨网段可能发现不到设备。
3. **教材库不在安装包里**，需要单独给。
4. **公式计算**：装了 LibreOffice 才算得准；没装的话，有些函数会直接报「不支持」，**它不会给你一个错的数**。
5. **PPT 字体**：第一次投影前，**请在本机打开一次确认字体显示正常**（它会尽量用 Noto Sans SC，但电脑上不一定有这个字体）。另外：**PDF 预览好看，不代表在 PowerPoint 里就好看**，请以 Office 里的实际效果为准。
6. **文件不能直接「双击打开」**：目前要把路径复制出来，自己去文件夹里打开。
7. **没有一键导出日志**（见第九节）。
8. **还没有别的老师用过**：目前所有测试都是作者自己做的。所以**你遇到问题非常正常**，请一定告诉作者。
