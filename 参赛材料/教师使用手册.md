# Mochi 教师使用手册

> **status**: active　**last_verified**: 2026-09-13　**verified_by**: Codex（源码级内容核对，未重新现场操作）

## 第一次使用

1. 安装与你的电脑匹配的安装包：Apple 芯片 Mac 使用 arm64，Intel Mac 使用 x64；Windows 使用 win-x64。版本选择见[交付台账](../docs/DELIVERY-LEDGER.md)。
2. 首次启动时，教师电脑选择「教师办公电脑」，教室大屏选择「教室一体机」。选错可以在 Mochi 托盘菜单中切换角色。
3. **先选择工作区**，让 Mochi 知道本次要处理哪个文件夹。制作课件、整理试卷或修改文件时，切换到**「工作」模式**再发送需求。
4. 按本次任务设置文件访问权限。演示流程使用“全部允许”的权限选项；它与校园业务的确认卡、账号角色权限是不同层，不能互相替代。
5. 输入简短明确的需求。例如：“制作一份四页节水课件，保存为 PPTX，再整理一页课堂练习。”生成后检查实际文件和内容。

Mochi 的模型访问凭据由安装包提供，通常不需要老师另填 API key。**校园查询、放行和校园沟通仍需要登录校园账号**；“模型开箱即用”不等于“校园业务免登录”。凭据失效或网络不可用时，请记录错误并联系维护者。

## 安装与角色

Mac 打开 DMG 后将应用拖入“应用程序”；Windows 运行 EXE 安装器。当前包未签名，系统可能要求额外确认；提示内容受系统版本与管理策略影响。核对安装包来源和系统提示，不把“未签名”解释为软件已被系统验证安全。

安装耗时受机器、磁盘和防护软件影响。旧包的小文件数量较多，后续包做过裁剪；没有该机器的实测耗时就不要承诺固定几分钟。

教师端与教室端采用不同运行角色及数据目录。教室端不应继承教师个人聊天和密钥；这不意味着两端完全没有共享数据，主动发送的文件、通知和回执就是协作内容。

## 创建和打开文件

- 先选工作区，再说明文件类型、内容和保存位置。PPT 任务应交付实际 `.pptx`，试卷按需要交付 `.docx` / `.pdf`，不要把一段文字当作成品。
- 以工具返回的**实际输出路径**为准；运行数据目录不等于默认成果目录。
- 当前侧边栏实现提供文件链接、成果项和文件浏览/打开能力。根据界面点击成果或文件路径；具体呈现取决于侧边栏设置和文件类型。
- 如果当前界面无法直接预览，可按返回路径用访达或文件资源管理器打开，再使用本机 Office、WPS 或合适的软件查看。
- 录演示时收起会遮挡成果的工作台与面板，再展示生成结果。

## 校园业务

先确认已连接正确的校园服务并登录相应角色账号，再提出需求。查不到、无权限、网络失败是不同结果；要求 Mochi 如实说明，不应将空结果理解为学生一定不在校。

- **查找学生**：例如“林小禾在不在校，最近在哪里？”展示的是校园业务记录；没有到达登记时应说明不确定，不能当作实时 GPS。
- **登记放行申请**：创建的是待审批申请，不代表已经批准放行。
- **批准放行**：核对学生、班级、目的地、时长和当前状态，在实际确认卡中确认。拒绝或取消后不应声称已完成。
- **到达与返班**：放行、到达、离开目的地、返班确认是不同步骤，按实际登记更新。
- **沟通老师、Agent 协作**：说清收件人和内容，按相应确认流程处理，再查看任务结果或回执。发送成功、送达、完成、人工“已看到”不能混为一谈。

校园写入工具在源码内请求确认；没有确认通道或未得到许可时拒绝执行。手动切到“工作”并不取消这些业务检查。

## 连接教室一体机

两台设备先选正确角色，配置学校与班级等身份，并处于允许相互通信的网络。教师端在「教室连接」中发现或手动连接目标，核对身份后发起相识/配对；按两端实际界面确认。教室端收到通知后，人工点击「我已看到」，教师端查看回执。

同一学校网络不一定表示网络互通；隔离 Wi-Fi 或跨 VLAN 可能影响自动发现。用户已确认 Windows 一体机功能实测正常，但具体网络拓扑和逐项截图尚未归档。

## 记忆与数据

可以询问已记住的内容，也可以要求忘记一条或清空长期记忆。当前记忆工具的确认要求写在工具描述中，**没有独立接入校园业务那种强制审批卡**；不能承诺每次都有相同弹窗。

清空会删除活动记忆记录，包括置顶记忆，但审计事件仍保留快照备查。**“清空记忆”不等于彻底擦除所有历史数据，也不等于清空聊天记录。** 当前未在本轮验证一键恢复或彻底擦除界面。

聊天、教材、成果文件及记忆是不同数据。删除前先确定对象与当前界面提供的操作，不建议老师直接批量删除运行目录；如需彻底重置，交由维护者确认备份和范围。本轮未验证各类删除入口，不再笼统声称全部没有按钮。

## 表格计算与结果检查

有 LibreOffice 时公式工具可调用它进行外部计算；没有时使用内置引擎，并报告计算来源。内置引擎支持一部分常用函数，未实现的函数会报告，例如部分查找或日期函数；这不表示 LibreOffice 也不支持它们。

请检查工具报告中的不支持项、错误值和回读结果。实现有检查不等于任何输入下都不会出错；用于正式材料前仍需核对。

## 报告问题

记录安装包版本、操作前一步、输入需求、实际结果与预期结果，并保存相关错误截图。不要在公开截图中包含密码、模型密钥或真实学生敏感资料。
