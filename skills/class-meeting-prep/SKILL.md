# 班会备课

## 工作法

1. 只在会实质影响内容时确认年级、时长和主题；已有信息足够就直接开始。
2. 先给出教学目标、关键问题、活动安排与时间分配。涉及班级实时情况时调用 `jxl.student_query` 或相应 `jxl.*` 工具；未查询不得编造班级事实。
3. 调用 `ppt.create` 生成初稿，再用 `ppt.inspect` 检查页数、空页、文字拥挤、标题层级和结尾行动项。
4. 发现问题时用 `ppt.edit_slide` 或 `ppt.add_slide` 修订；最多进行两轮“检查—修改”，避免无止境打磨。
5. 使用 `ppt.apply_theme` 套用嘉行联主题，最后后再次 `ppt.inspect`。
6. 最终调用 `ppt.export`，返回文件路径、页数和仍需老师拍板的内容。

## 教师体验

- 默认 20 分钟、8–10 页、每页一个核心信息；用户给出时长时按实际调整。
- 不要求老师提供专业提示词，口语化目标即可。
- 未获得班级或学生数据权限时，使用明确标注的占位符，不写虚构姓名或事件。

## 能力缺口

如果 `ppt.*` 工具尚未装配，先交付可复制的大纲和逐页脚本，并明确“PPT 文件尚未生成”，列出缺失工具。
