# 教学材料查找

## 资料边界

先读同目录的 `teacher-resources.json`。它只记录来源、版本待确认项和许可边界，不包含教材全文，也不能代替具体页面的授权核验。

- 高中资料默认优先人教版；英语优先外研版。外研版英语的具体版本和册次仍须教师确认，不能自行补全。
- `textbook-library` 只能作教材目录索引：其代码的 MIT 许可不覆盖教材正文。
- OpenStax Biology 2e 仅作英文生物补充参考，许可为 `CC BY-NC-SA 4.0`；使用前保留署名并核对非商业、相同方式共享等条件。
- 不下载版权不明资源，不把搜索摘要写成已读全文，不把链接存在说成"教材全文知识库已经建好"。

## 隐私门禁

外网检索前，只保留学科、年级、知识点和用途等非个人条件。学生姓名、学号、联系方式、健康、考勤、成绩、处分、家庭信息，以及可识别的附件内容都不得进入外网 query 或上传到外部资料站。

若老师的问题同时包含个人资料和通用教学主题，先用授权校园/本地工具处理个人资料；只有能明确剥离后的通用主题，才可单独查外部资料。网络资料不是本班学情证据。

## 三级查找流程

教材对应内容按以下顺序查；用户明确指定文件或来源时先读指定材料。命中必须相关、版本匹配且足以回答，不能找到任意一页就停止。查无结果、不可用与无权限分别说明。

### 第一级：本机教材库（找"教材对应内容"首选）

1. 用 `mochi_knowledge_search` 检索。查询词给清楚的中文知识点、单元或活动名；需要时按学科、册别过滤。
2. 判断命中：工具返回了真实书名、册别、页号和短片段，才算命中。
   - 返回空，或只返回明显不相关页，就是**没命中**。写"本机教材库里没查到相关页"，不要用低相关材料凑答案。
3. 命中后：
   - 要看这一页的可检索文本和原页引用，用 `mochi_knowledge_page`，只传 `mochi_knowledge_search` 返回的教材ID和页号。
   - 要拿这一页的图，只有目录确有 `mochi_knowledge_page_image` 且模型能接收图像时才调用；无法看图则说明原页视觉未核验。
   - 返回里有"此页来自 OCR"的提醒时，**必须说明公式、图表和精确原文要回受管 PDF 原页核对**，不要把 OCR 文本当唯一依据。
4. 这两个工具都只读，也不能传本机路径、URL 或别的文件名。

### 第二级：允许目录里的现成材料

1. 用 `file_search` 查当前工作区和允许目录，命中后按类型取内容：

   | 文件类型 | 工具 |
   |---|---|
   | Word / 文档 | `doc_read` |
   | PDF | `pdf_read` |
   | 演示文稿 | `ppt_inspect` |
   | 表格 | `spreadsheet_read` |
   | 纯文本 | `file_read` |
   | 图片 | 目录存在且模型支持时用 `read_image` |

2. 判断命中：真的读到了正文才算命中。**工具没返回内容就说没读到，不要凭文件名猜内容。**
3. 老师要整理文件时，先展示拟创建的目录与移动清单，再用 `file_create_folder`、`file_copy`、`file_move`、`file_rename`，按当前审批策略执行。

### 第三级：联网权威源

1. 本地不够时才调用原生 Web 搜索。先看返回 `content` 里的范围说明：
   - 写明"经可信来源域名校验的 SearXNG 结果"时，只使用返回的来源链接；不要用 `site:` 查询语法代替来源校验。
   - 写明"中文维基百科"或"配置的百科检索接口"时，结果只可作百科参考，不能当课程标准、教材正文或权威教辅依据。
   - 未配置或失败时，说明实际覆盖的本地范围，不编造外部结果。
2. 优先顺序：国家级官方平台（国家中小学智慧教育平台、教育部、人教社）> 省级官方 > 市级官方 > 主流教辅题库。这是排序权重，不是白名单。
3. 只有资料目录里列出的权威域名，或本次检索已经校验的来源 URL，才可以打开。网页没抓到正文就写"仅根据检索摘要判断"。
4. 下载这件事说实话：商业题库的试卷多数要登录或付费，只能给链接；官方平台的公开附件取到了才算取到；**绝不伪造下载链接或本地文件路径。**

## 引用规范

引教材内容，**必须给到「册次 + 页码 + 来源」三样**：哪一册（比如必修一）、第几页（PDF 页号或印刷页号，写清用的是哪个）、来源是什么。

- 页码只采信 `mochi_knowledge_search` / `mochi_knowledge_page` 真实返回的页号，或已读取文件里真实存在的页码。
- **找不到页码时，只能给到章节级**（比如"第 X 章第 Y 节"），并说明"只能定位到章节级"，不硬凑一个页码。
- **不许编页码、编引用格式、编作者、编出处、编官方题名和年份。**
- OCR 页的页码和原文都要标"待核对原页"。
- 参考文献只有真实查到的资料才编排。

## 找配图

**先分清要什么样的图：** 真实照片/实物图、知识点示意图、还是可交互的图形。

1. **优先取本机已有**：老师给的材料里的图、教材库命中页的图（`mochi_knowledge_page_image`），这些来源最可靠。
2. **需要外部图片时**，用图片查找能力（`image_find`）按知识点关键词找候选。**若该能力在当前会话不可用，就说明"当前只有本地素材可用"，不要假装找到了外部图片，也不要随便拿一张装饰图充数。**
3. **需要改图时**用 `image_edit`；**需要按知识逻辑画图时**用 `diagram_draw`（比如受力分析图、流程图、函数图像）。同一句兜底：能力不可用就说清实际范围。
4. **需要判断一张图配不配这节课**时用 `teaching_image_match`；不可用就自己按"是否真实反映知识点、是否清晰、是否有版权风险"逐条说明。
5. **配图硬规则**（无论用什么工具都要守）：
   - 图必须真实反映知识点，不用纯装饰图充页数。
   - 等比缩放，不拉伸、不压扁。
   - 外部图片要说明来源和许可状态；来源不明就不放进给学生的成品。
   - 找不到合适的图，就说没有，不要凑。

## 返回格式

按"可直接使用、需要改编、仅作参考"三档返回 3–6 个高相关结果。每项说明：适用年级、用途、**来源**、**册次+页码（或说明只能到章节级）**、以及许可/待确认点。

## 能力缺口

缺少某级能力时，说明实际搜索过的范围与未覆盖范围，不编造材料存在。外网搜索适配器本身无法判断任意 query 是否含个人资料；调用前的隐私门禁仍是必须执行的规则。
