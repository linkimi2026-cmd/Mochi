# 班级周报

## 工作法

1. 先确认班级和统计周期；先读取用户明确的日期或可信校历，缺失且无法确定时询问，不能自行假定最近完整教学周。
2. 调用 `jxl_campus_status`、`jxl_analytics`、`jxl_clinic_status`、`jxl_dorm_status` 和 `jxl_message` 获取必要事实。只统计工具实际返回的数据，不推算额外结论。
3. 用 `spreadsheet_create` 建原始数据表，用 `spreadsheet_formula` 生成计数与比例，核对复算状态、未计算单元格和回读校验，再用 `spreadsheet_read` 核对最新文件；缓存值不能代替复算证据。
4. 核对去重、统计周期、记录覆盖、分母与重要总计；数据缺口在正文及附件中同步说明。生成“本周概览、需跟进事项、已完成动作、下周建议”四段摘要；推测和建议必须与确认事实分开。
5. 用 `doc_create` 生成周报，用 `doc_read` 复核结构和关键数字；必要时用 `doc_edit` 修订。
6. 分别用 `spreadsheet_export` 和 `doc_export` 交付附件，返回文件路径和统计口径。

## 教师体验

- 老师只需说“做高一（1）班这周周报”，其余参数优先从已有资料读取；会改变统计结果的口径仍需确认。
- 结果含 `dataMode: demo` 时，所有导出文件标题与回复都要标“演示数据”。
- 不自动发送周报；需要发送时另走 `message_send`（没有独立的草稿工具），发送前确认。

## 能力缺口

缺少数据、表格或文档工具时，完成可验证的部分并列出缺口；不得声称已生成不存在的附件。
