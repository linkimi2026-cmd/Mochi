# Mochi 审美法则 · 通用层

> 这份文件不规定"用什么颜色"。它教的是**怎么根据手上的内容，做出有品味的选择**。
>
> 一份为朱自清《春》做的材料，和一页物理力学讲义，**配色、字体、装饰都应该完全不同**——
> 如果它们长得一样，那不是规范执行得好，是**设计失败了**。

## 文件层级声明

- 本文件是**通用法则**，适用于 Mochi 的**所有视觉产出**：课件（.pptx）、文档（.docx）、
  讲义与报告（.pdf）、图表、插图、页面。
- 同目录另有三份配套文件，**生成前一起读**：
  | 文件 | 管什么 |
  | :-- | :-- |
  | `design-principle.md`（本文） | 通用审美法则：怎么定调、怎么避雷、怎么自检 |
  | `layout-library.md` | 版式库：L01–L20 幻灯片合约 / D01–D08 文档合约，含换算好的坐标与字号 |
  | `pptxgenjs-hard-rules.md` | 生成器硬规则：pptxgenjs 的踩坑清单、字体安全清单、字体在渲染回看中的可信度 |
  | `designs/design-principle.classroom.md`、`designs/design-principle.document.md` | 场景分支：课堂/答辩、文档/讲义的具体题材做法 |
  | `story-principle.md` | 内容叙事：意图对齐 → 骨架节奏 → 逐页大纲 |
- `designs/` 是**场景分支**——某一类场景的风格知识包。分支给出的色值与字体是
  **起点参考，不是必须**；内容需要时应当改。
- 冲突解决优先级：**老师显式指令 ≻ 分支结构层 ≻ 通用法则**。
- 🔴 **最重要的一条**：本文档中出现的**任何具体色值都只是示例**。
  判断依据永远是"**它是否贴合这份内容**"，而不是"它是否等于文档里写的那个值"。

## §0 审美决策：先想清楚，再动手

**这一步不能跳。** 直接开始排版的结果，一定是"AI 味"——因为模型在没有约束时，
会自动收敛到训练数据里最常见的样式（白底、紫色渐变、四个等宽卡片、Inter 字体）。
这不是能力问题，是**分布收敛**：不确定的时候，模型会滑向平均值。

所以要先**主动选定方向**，把选择从"默认值"手里抢回来。

### 0.1 读懂内容（Grounding）

动手前先回答：

- **这份材料在讲什么？** 具体到题材本身。
- **它的"物质世界"是什么？** 颜色、材质、光线、季节、场景——
  **题材自己会告诉你它长什么样**。
- **谁来读/看？** 学生？评委？家长？同事？他们的期待是什么？
- **场合是什么？** 课堂投影 / 打印讲义 / 答辩大屏 / 手机查看？

> **题材会说话，去听。**
> 《春》：草色、柳黄、桃红、雨后的灰绿、湿润的土——这些就是它的颜色。
> 力学：钢蓝、冷灰、白、警示橙——工业与精确。
> 长征：土黄、赭石、旧纸灰、暗红——岁月与重量。
> 古诗文：宣纸米、松烟墨、朱砂、青灰——书卷气。
> 化学实验：白瓷、浅蓝、透明感、警示色点缀。
>
> **反过来做**：先选一个"好看的颜色"，再把内容塞进去 —— 这一定会翻车。
> 颜色应该是从内容里**长出来**的。

**判断标准**：把你选的这套配色，套到一份**完全不同题材**的材料上。
如果照样"说得过去"，说明你没有为这份内容做特定选择，只是又滑回了默认值。

### 0.2 定调性（选一个强立场）

沿这几个轴**选一个明确的位置**，不要待在中点：

| 轴 | 一端 ←→ 另一端 |
| :-- | :-- |
| 密度 | 疏朗留白 ←→ 密实饱满 |
| 气质 | 严谨克制冷 ←→ 温暖亲和 |
| 时代 | 传统书卷 ←→ 现代简洁 |
| 色彩强度 | 单色克制 ←→ 色彩饱满 |
| 正式度 | 轻松活泼 ←→ 庄重正式 |

**"中间是最糟糕的位置。"** 平淡、不敢表态的设计，正是"AI 味"的标志。
选了"传统书卷"就往宣纸、竖排、朱砂印走；选了"现代简洁"就大胆留白、粗字重、无装饰。
**两种都对，模棱两可才错。**

**把胆量花在一个地方。** 一份材料里只留**一个**让人记住的元素，其余全部克制、安静。
这是"高端"和"花哨"的分界。出门前照镜子，摘掉一件配饰。

### 0.3 定色板

**不要从取色器开始，从调性开始。** 问自己：
> "这个调性，会自然生长在什么颜色里？"

色板构造要点：
- **主色 + 强调色** 的结构优于"均匀分配的几个色"。
  一个占主导的颜色 + 一个尖锐的强调色，比五个各占 20% 的颜色有力量得多。
- 色彩灵感可以从**非设计领域**来：自然、建筑、电影、传统器物、季节、材料。
- 全篇色彩池 **≤4 个**（不含黑白色阶）。多了必然乱。
- 面积分配（**6-3-1 法则**）：**主色 60%、次色 30%、强调色 10%**。
  强调色是"手术刀"，只切在最需要被看见的地方。
- **禁止纯黑铺底**。用带主色倾向的近黑（如 `#141314`、`#0E1420`）代替 `#000000`。
- 中性色**全程只用一套**：不要在同一份材料里既用暖灰又用冷灰。

### 0.4 定装饰

装饰不是"加点东西让它好看"，而是**用视觉语言重复一遍内容的气质**。
详见 §6 装饰系统。

## §1 反收敛铁律（Anti-Convergence）★

**这是本文件最容易被忽略、也最影响"像不像人做的"的一节。**

模型有一个顽固的坏习惯：**每次生成都收敛到同一套选择**。
第一次用了某套配色和字体，之后每一份材料都长一个样。
这会让同一台机器产出的所有东西看起来**是同一个模板灌出来的**——
对用户来说，这就是"丑"和"廉价"的来源。

### 规则

1. **换。** 上次这份材料用了什么色系和字体，这次换一组。
   连续产出多份材料时，彼此的视觉语言必须明显不同。
2. **不要用"安全牌"。** 以下是被过度使用到失去个性的默认选择，
   **只有当它们确实是内容最优解时才允许使用**：
   - 颜色：紫蓝渐变、商务深蓝 `#1F4E79` 万能打底、"科技蓝 + 青色"万能组合、
     暖米色底 `#F4F1EA` 配陶土橘 `#D97757`
   - 字体：永远只用系统默认黑体、永远正文标题同字体同字重、Inter / Roboto / Arial 打天下
   - 布局：永远是"四个等宽卡片"、永远"居中大标题 + 三行小字"
3. **字号要跳跃，不要等差数列。** 标题 32 / 正文 28 / 注释 24 是最难看的比例。
   正确做法是 **3 倍以上的落差**：72 的锚点配 18 的说明。
4. **字重对比要极端。** `100/200` 配 `800/900`，而不是 `400` 配 `600`。
5. **装饰要有理由。** 加编号标记（01/02/03）**只在这确实是序列时**才对——
   流程、步骤、时间线。把并列的概念硬编成 01/02/03，是"生成物"的典型破绽。
6. **不要每页换一套版式，也不要页页同一套。** 全篇用 **3–5 种版式**
   轮换，重页用最特殊的那个。

> 判断标准：**把这份材料混在一堆同类材料里，它认得出是自己的吗？**
> 如果每一份都长一样，说明反收敛没做到。

## §2 绘制前清单（必须先写出来，不能只在脑子里想）

**在放第一个元素之前，把这五项写下来。** 写了才不会滑回默认值。

1. **版式合约编号**：从 `layout-library.md` 里选一个（L?? / D??），
   或写明"混合"及理由。
2. **色板**：主色 / 次色 / 强调色，每个给出 hex 和角色。
3. **字体**：最多 2 套（或 1 套 + 不同字重），各给角色。
   **必须核对 `pptxgenjs-hard-rules.md` 的字体安全清单**——用回看环节渲染不出真实宽度的
   字体，等于放弃了自检能力。
4. **字号表**：把你要用的每一个文字角色列出来，附确切字号。例如：

   ```
   封面主标题   54
   页标题       32
   正文         18
   数据锚点     72
   注释/页脚    12
   ```

   任何一个低于**下限**（投影 ≥14pt / 打印 ≥10.5pt）→ 停下来砍内容，不要缩字号。
5. **视觉锚点**：这一页 / 这一份材料里，哪一个元素最大、最抢眼。
   **必须只有一个。**

## §3 结构与排版总则

1. **密度优先 —— 空 ≠ 极简，空 = 没做完。**
   极简成立的前提是单个元素信息量足够大。一页只有一行字配大空白，不是高级，是内容不够。

2. **每个版面必须有一个视觉锚点。**
   眼睛需要落点。至少有一个明显大于其他的元素——大字号关键信息、占满一栏的图、大色块。
   **禁止所有元素大小趋近中间值。** 锚点与次一级元素的体量比应 **≥3:1**。

3. **留白围绕焦点，不能均匀散布。**
   如果每两个元素之间的空隙都差不多大，那不是留白，是没排满。
   正确做法：焦点周围留足呼吸空间，其余元素紧密成组。
   **组间距 ≥ 组内间距 × 3。**

4. **全篇要有起伏。**
   多页材料必须有重页（视觉高潮）与轻页（信息承载）之分。
   连续 3 个版面视觉重量相同 → 必须打破。
   参考"三明治"节奏：深色封面 + 结尾 / 浅色正文；或全程深色做高级感，但**不能随手混用**。

5. **一切对齐到一个系统。** 共用左边线、共用基线、共用栅格列。
   **肉眼凑齐是禁止的。** 大多数问题在"差 2mm"这个量级上就已经看得出来了。

6. **装饰服务于内容，不是填充。** 见 §6。

7. **每一页都要有视觉元素。** 纯文字页是最容易被遗忘的。
   图、表、图标、形状、大数字——至少有一个。

8. **用到的工具函数（pptxgenjs）**：不要为了"视觉丰富"去叠一堆装饰形状。
   先问"现有构图能不能更凝练"，而不是"要不要再加一个图形"。

## §4 色彩法则

- **6-3-1 面积比**：主色 60% / 次色 30% / 强调色 10%。强调色超过 15% 就失去"强调"的作用。
- 文字与底色的对比度：**正文 ≥4.5:1，锚点大字 ≥7:1**。
  浅色字压浅色底、深色字压深色底，都是硬错误。
- 全篇色彩池 **≤4 个**（不含黑白色阶）。
- **禁止**同一版面出现两套色板；**禁止**高饱和撞色铺满 ≥1/3 面积。
- **禁止**纯黑 `#000000` 大面积铺底；**禁止**纯白 `#FFFFFF` 当默认底而不做任何交代
  （要留白就明确它是"留白"，不是"忘了设计"）。
- 尽量做**色盲友好**：不要让红绿成为唯一的区分手段；同时用深浅或形状编码。

## §5 字体与字号阶梯

- 字体家族 **≤2 套**；标题与正文**允许不同个性**（标题衬线、正文黑体是稳妥的搭配）。
- **字号跳跃 ≥3 倍**（锚点 vs 正文）。
- **字重对比要极端**（`100/200` vs `800/900`，不是 `400` vs `600`）。
- 正文字号下限：**投影 ≥14pt、打印 ≥10.5pt、屏幕 ≥15px**。
  **内容放不下就砍内容 / 换版式 / 分页，永远不要缩字号。**
- 中文正文默认 `Noto Sans SC`；**标题可以选更有表现力的字体**，不要全篇一个字体走到底。
- **字距/行距**：
  - 行距用**绝对值**，不要用倍数（`1.2` / `1.5` 这种会让渲染器自己发挥）。
  - 大字标题行距收紧（约为字号的 `0.95–1.1` 倍）；正文行距放松（`1.3–1.5` 倍）。
  - 小标签加宽字距（`+5%~+15%`），大字标题略微收紧（`-1%~-3%`）。
- **禁止**：楷体/行书/毛笔体做正文、艺术字、空心字、3D 字、阴影字。
- **禁止全大写做正文**（只用于短标签）。

## §6 装饰系统

装饰是**用视觉语言把内容的气质再讲一遍**。它必须来自题材，不能是通用的"点缀零件"。

### 6.1 先判断：要不要装饰

| 判断 | 处理 |
| :-- | :-- |
| **老师明确要求"纯文本""朴素""不要花哨"** | **不加装饰**。只用排版本身做层次：字重、字号、留白、细线分隔 |
| 内容本身有强烈色彩/季节/情绪意象（文学、自然、节日） | **应当加**，且要贴合题材（见 6.2） |
| 内容偏理性/数据/流程 | 装饰应**克制且结构化**——用图表、编号、细线，不用花纹 |
| 正式文书（通知、公函、成绩单） | **极简**，只保留必要的分隔与标识 |

> 老师说"加些装饰"，不是让你随便贴图案——是让你用视觉呼应内容。
> 老师说"纯文本"，**就真的不要加**，这时候克制本身就是审美。
> **少加装饰，比多加装饰更常见地是正确答案。**

### 6.2 装饰从哪里来（按题材找）

| 题材 | 可用的装饰语言 |
| :-- | :-- |
| 《春》《荷塘月色》等写景散文 | 草叶、柳条、花瓣、水纹；色调用草绿、柳黄、桃粉、雨灰；可用大面积柔和色块 |
| 古诗文、文言 | 宣纸纹理、竖线、朱砂印形、墨点、书页边栏 |
| 历史 / 人物 | 旧纸色底、年代细线、档案感边框、老照片式留白 |
| 自然 / 生物 | 叶脉、细胞结构、水波、地形线 |
| 物理 / 力学 | 受力箭头、坐标线、网格、刻度、精确的细线 |
| 化学 | 分子结构、试管轮廓、滴液、透明质感 |
| 地理 | 等高线、经纬网、地图色块 |
| 数学 | 函数曲线、几何辅助线、坐标系、公式框 |
| 音乐 / 美术 | 五线谱线、色块、笔触、留白 |
| 科技 / 信息 | 网格、数据线、节点、极简几何 |

### 6.3 装饰的四条纪律

1. **少而准。** 一处到位的装饰胜过十处零碎点缀。通常每个版面 **≤2 类**装饰元素。
2. **装饰不能压过内容。** 装饰元素的不透明度通常 ≤30%，或面积 ≤15%。
   **装饰抢占视线 = 失败。**
3. **全篇统一。** 同一份材料里的装饰必须来自同一套视觉语言。
   第一页是水墨，最后一页不该出现像素方块。
4. **禁止无来源的装饰零件**（这些是"AI 味"最集中的地方，见 §8）：
   - 纯装饰性的几何小图形（小三角、小圆点）随意散落
   - 通用"科技感"光效、光晕、粒子、霓虹外发光
   - **把并列概念硬编成 01/02/03**（只在真序列时用）
   - 与内容无关的边框、阴影、渐变
   - 用免费图标库里的通用图标充数

> **检验标准**：把装饰全部去掉，内容还成立吗？成立——那装饰是可选的美化，可以留；
> 装饰去掉后版面垮了——说明你把装饰当成了内容，返工。

## §7 内容密度门禁

**这是"丑"的第二大来源，仅次于无锚点。**

| 版面类型 | 正文字数下限 | 内容区占用 |
| :-- | :-- | :-- |
| 封面 | 20 | ≥50% |
| 目录 / 提要 | 60（合计） | ≥70% |
| **正文页** | **180** | **≥80%** |
| 卡片组 | 每卡 ≥60，合计 ≥200 | ≥80% |
| 数据 / 图表页 | 80（含 ≥1 个关键结论） | ≥85% |
| 过渡 / 分隔页 | 25 | ≥60% |
| 结束页 | 20 | ≥40% |

补充：
- **容器填充率 ≥80%**。内容不够就换版式或合并，**不要用空白撑高**。
- 尾部元素（引文条、标签、结论句）必须**锚底**，禁止悬在容器中段。
- 常规版面留白 **≤30%**（封面/过渡页不受此限）。
- **数据必须落点**：关键数值之后必须补一句判断，三选一——
  含义解释（`62% → 说明多数学生卡在第二步`）、
  教学启示（`→ 下节课需补符号处理专项`）、
  影响说明（`→ 但样本仅 32 人，结论需谨慎`）。
  **只摆数字不给判断的版面，是信息板，不是给人看的东西。**

## §8 AI 味破绽清单（出现任一即返工）

这份清单合并了两个来源：**WorkBuddy 官方 ardot 设计规范**的 AI Tells，
和 **Anthropic 官方 pptx 技能**的 Avoid 清单——两者对同一批破绽的判定高度一致，
说明这些是跨模型的通病。

### 颜色
- ❌ **紫蓝渐变"AI 紫"**（`#7C3AED` 一类）铺底或做按钮/标题发光。
- ❌ **暖米底 + 陶土橘**（`#F4F1EA` + `#D97757` 这个组合）——已是新一代最明显的破绽。
- ❌ **纯黑 `#000000` 大面积**；用带色倾向的近黑代替。
- ❌ **高饱和强调色**（饱和度 >80%）；降下来才显得高级。
- ❌ 色彩数量超过 4 个角色。
- ❌ **默认蓝**（`#1F4E79` / `#1D4ED8` / `#4472C4`）——没有依据就用蓝，等于没做选择。

### 形状与装饰
- ❌ **标题下方加一条横线**（accent line under title）——AI 生成幻灯片最典型的标志。
  要分隔就用留白或底色块。
- ❌ **装饰性色条 / 色带**，包括：横贯整页的页眉页脚色条、贴边竖条、
  卡片边上的一条细线、"单边描边"矩形。这些读起来就是 AI 填的。
  想突出一个卡片，用**淡底色、投影或图标**，不要用边条。
- ❌ **外发光 / 霓虹光晕**；要边缘感就用内描边或带色投影。
- ❌ 一条渐变从深到浅反复用在每个元素上。
- ❌ emoji 或 Unicode 符号（☀️ ✓ ▶ ★）当图标用 —— 要么用真矢量图标，要么不用。

### 版式
- ❌ **三个等宽卡片横排**（"三栏特性介绍"）——换成交错布局、非对称栅格或横向滚动。
- ❌ **居中的大标题 + 三行小字**（当版式变量允许时，居中英雄区是禁的）。
  改用 50/50 分栏、左文右图、或刻意留白的不对称结构。
- ❌ 每页同一个版式；或每页都换版式导致无统一性。
- ❌ 框套框套框；每个元素都装进一个圆角卡片里。
- ❌ 所有元素一样大（没有锚点）。
- ❌ 正文居中排（正文一律左对齐，只有标题可以居中）。

### 文字与内容
- ❌ **占位感人名/品牌名**（"张三""李四""Acme""Nexus""SmartFlow"）——
  用可信的真实感名字或直接不写。
- ❌ **假整数**（`99.9%`、`50%`、`100%`）——用有零头的真实感数据（`47.2%`、`61.3%`）。
- ❌ **空话词**（"赋能""无缝""一站式""全新升级""引领未来"）——换成具体动词和事实。
- ❌ 段段落落写满小字（正文段落别超 3 行居中/超 4 行左对齐）。
- ❌ 把散文直接塞进幻灯片；幻灯片是辅助视线，不是文档。
- ❌ **占位文字未清零**（`TODO`、`[insert]`、`XXX`、`lorem`）。

## §9 绘制后审计与收敛阈值

### 9.1 必做的两层验证

| 层 | 手段 | 查什么 |
| :-- | :-- | :-- |
| **结构层** | 读产物 / `ppt_inspect` / 生成器自检 | 页数、缺页、文字是否真的写进去了、表格图表是否为原生对象 |
| **视觉层** | **`mochi_ppt_render` 渲染成图，亲眼看** | 裁切、溢出、重叠、偏空、对比度不足、装饰抢占视线 |

🔴 **视觉层不能省。** 你已经知道文字是什么、打算放在哪，–
所以看图时会**看到你以为的东西，而不是真实渲染出来的东西**。这是"自检偏差"。
必须当作第一次看见这份材料来审。

### 9.2 视觉层审什么（按顺序，先看最常出错的）

1. **文字溢出 / 被裁切**（最常见，也最丢人）——文字跑出文本框或页面边界。
2. **元素重叠**——文字压在形状上、线穿过字、块与块叠在一起。
3. **页脚 / 来源标注与正文打架**。
4. **间距**：元素间距 <0.3" 或块与块几乎贴上；或反过来，一处大空、一处挤爆。
5. **边距**：内容距页边 <0.5"。
6. **对齐**：并列元素没对齐到同一条线。
7. **对比度**：浅字压浅底 / 深字压深底。
8. **卡片/分栏宽度不均**导致换行量差异巨大。
9. **整体**：配色是否同出一源？锚点是否够醒目？全篇节奏是否有起伏？

### 9.3 收敛阈值 —— 什么时候停

自检回路必须**会终止**，否则会陷入无限微调。

1. **硬上限：每个版面最多 2 轮修改。** 第 3 轮开始前停下来，把剩余问题记录下来。
2. **忽略橡皮擦级别的噪音**：间距差 ≤4px、亚像素错位、
   装饰层元素的轻微溢出、不属于当前版面范围的问题。
3. **禁止主观再打磨**：一旦这个版面符合规范、没有结构问题，
   **不要再渲一次"确认一下"**，也不要去找"还能不能更好看"。交付。
4. **不要编造问题**：只修结构层和视觉层真实报出的问题。
   但同时——**不能因为结构干净就放过肉眼可见的破绽**。
5. **同一轮里发现的所有问题，攒起来一次改完**，改完再验一次，
   不要一个小改动渲一次。

## §10 交付前硬闸门

出现任一情况必须返工：

1. 内容区未撑满，或留白 >40%（功能性留白除外）
2. 没有视觉锚点，所有元素大小趋近
3. 正文字号低于下限
4. **配色/字体与上一次产出雷同**（反收敛未落实）
5. 强调色 >10%（重页 >15%），或出现与题材无关的颜色
6. 装饰与题材无关，或装饰抢占视线
7. 关键数据只摆数字、不给判断
8. 容器填充率 <80%，或尾部元素未锚底
9. 全篇视觉重量无起伏
10. **命中 §8 清单任意一条**（标题下划线、装饰色条、三栏等宽卡片、AI 紫、假整数…）
11. **文字溢出、被裁切、元素重叠**——必须**渲染成图亲眼看**确认，
    不能只检查文件结构。结构完全正确而画面已经坏了，是最常见的隐性缺陷。
12. 占位文字未清零
13. 公式、数据、史料、引用系杜撰
