# Mochi 课件叙事法则 · 内容层

> 设计法则管"看起来怎么样"，这份文件管"**讲了什么、怎么讲**"。
> 一份课件可以先输在内容上：页页都是信息罗列，没有观点、没有推进、没有落点。
> 这种课件即使排版精美，也只是"好看的资料汇编"。

## 使用顺序

写内容大纲时**必须按顺序完成三步**，前一步未完成不得进入下一步：

1. **意图对齐** → 2. **骨架与节奏** → 3. **逐页大纲**

---

## ① 意图对齐

先用一段话回答清楚这 5 个问题。答不上来就不要开始写内容。

- **受众是谁**：这节课给谁讲？学生的知识起点在哪？是新课、复习课，还是公开课/答辩？
- **讲完希望他们记住什么**：一句话。如果总结不出这一句，说明你自己还没想清楚。
- **篇幅**：总页数。这决定重页配额（10 页配 2–3 页，15 页配 3–4 页）。
- **调性**：用 3–5 个词锁定（如"严谨清晰 / 亲切活泼 / 沉稳人文 / 紧张备考"）。
- **边界**：哪些必讲？哪些不讲？哪些话题不碰？

> 教师场景补充：如果是**课堂用**，正文必须能在 40 分钟内讲完，页面密度要允许学生记笔记；
> 如果是**答辩/展示用**，页面可以更疏、更重视觉冲击，因为它是给人"看"的，不是给人"抄"的。

---

## ② 骨架与节奏

回答清楚：

- **章节划分**：分几章，每章几页。
- **目录 ↔ 章节页契约（强制）**：目录声明了 N 章，就必须**有且仅有 N 个章节过渡页**，
  编号连续（01..N），标题文字与目录条目**逐字一致**。不允许合并、跳过、缺页。
- **重页定位**：先标出哪几页是重页。封面与结束页默认算重页，中段再选 1–2 页。
  确认重页占比在 20–30%，且任意两个重页之间至少隔 1 个轻页。
- **节奏曲线**：给每页标 `peak`（高潮）/ `valley`（蓄力）/ `transition`（转场）。
  连续 ≥3 页 `valley` → 必须插入 `peak` 或 `transition` 打破沉闷。

**骨架未确认 → 禁止开始逐页写内容。**

---

## ③ 逐页大纲

每页必须写清这些字段（缺任一字段即为不合格）：

| 字段 | 说明 |
| :-- | :-- |
| `title` | 页标题——**写观点，不写分类名** |
| `role` | `hero`（重页）/ `supporting`（轻页）/ `transition`（转场） |
| `rhythm` | `peak` / `valley` / `transition` |
| `layout` | 版式（见设计法则 §5） |
| `density` | `字数约 XXX / 视觉 N 个 / 留白约 XX%` |
| `anti_pattern` | **本页具体禁止的排版方式**（不得写"避免单调"这类空话） |
| `takeaway` | 这一页讲完，学生应记住的那**一句判断** |

### 标题要写观点，不要写分类

| ❌ 分类名 | ✅ 观点 |
| :-- | :-- |
| 实验数据 | 温度每升高 10℃，反应速率约翻一倍 |
| 课文分析 | 祥林嫂的三次出场，一次比一次沉默 |
| 课后总结 | 这道题的陷阱不在计算，在单位的隐藏换算 |

分类名是**目录**的语言，观点才是**页面**的语言。全篇标题都是分类名 → 课件退化成提纲。

### 数据必须落点

关键数值 / 比例 / 排名 / 年份 / 实验结果后，必须补一句判断（含义解释 / 教学启示 / 影响说明）。
**只摆数字的页面 = 信息板，不是课件。**

### 版式与内容必须匹配

| 内容类型 | 最佳版式 | 必须避免 |
| :-- | :-- | :-- |
| 核心数据 / 关键结论 | 巨型数字 + 环绕说明 | 把数字塞进等宽卡片 |
| 概念定义 | 左标题条 + 右正文 | 居中大段文字 |
| 并列要点 | 卡片组（全篇 ≤3 次） | 四卡等宽横排 |
| 对比论证 | 非对称双栏（65:35） | 50:50 等分 |
| 流程 / 步骤 | 横向节点串 | 垂直长列表 |
| 实验 / 案例展示 | 左大图 + 右文字 | 图缩小成贴片 |
| 课堂练习 | 题目区 + 留白答题区 + 提示条 | 题目和答案同页 |

## 教师课件专项约束

### 内容真实性（红线）

- **公式、定理、数据、史料、引用必须真实可考**。禁止编造公式、虚构数据、编造引用。
- 课堂示例数据必须标明来源或明确标注"示例"。
- **涉及具体学生的成绩、表现**：只能用于班级整体分析，不得指名道姓做负面评价。

### 学生端课件的三条额外规则

1. **一页一个知识点**。多个知识点挤在一页，学生记不住也抄不完。
2. **练习页必须留答题空间**。题目占满整页 → 学生无处下笔，这页就废了。
3. **关键结论必须落成一句话**，不要让学生自己从一堆数据里总结——那是老师的活儿。

### 答辩 / 展示课件的三条额外规则

1. **前 3 页决定评委印象**：问题、价值、做法，不要用"背景介绍"开场浪费黄金位置。
2. **每页一个论点**，论据跟随，不要在一页里塞三个论点。
3. **结尾页要给"记忆点"**，不要用"谢谢观看"收场。

## 交付前 Checklist

- ❌ 全篇重页 <2 个或 >35%
- ❌ 连续 ≥3 页同为 `supporting + valley`（无视觉起伏）
- ❌ 卡片组版式出现 ≥3 次
- ❌ 非对称版式占比 <40%
- ❌ 任意相邻两页版式相同
- ❌ 任一页缺少 `role` / `rhythm` / `layout` / `anti_pattern` / `takeaway`
- ❌ 含关键数据的页只摆数字、不给判断
- ❌ 章节过渡页数量 ≠ 目录声明的章节数，或编号不连续
- ❌ 全篇标题都是分类名（"实验数据""课文分析"），没有观点
- ❌ 出现杜撰的公式、数据或引用
