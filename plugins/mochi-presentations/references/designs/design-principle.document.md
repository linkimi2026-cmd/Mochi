# design-principle.document.md · 文档与讲义场景

> 通用层「先确定设计依据」 同样适用。这份文件处理的是**纸面与阅读**场景：讲义、文章、报告、通知、试卷、阅读材料。
> 它与课件（投影）的根本差别：**读者离得近、停得久、会逐字读**。
> 所以文档的审美不靠冲击力，靠**呼吸、节奏与质感**。

## 1 与课件的根本差别

| | 课件（投影） | 文档（纸面/阅读） |
| :-- | :-- | :-- |
| 观看方式 | 远距离、扫视、几秒 | 近距离、逐字、几分钟 |
| 字号 | 大（正文 ≥18px） | 小（正文 10.5–12pt） |
| 密度 | 每页信息少而重 | 每页信息可以密，但要**有呼吸** |
| 锚点 | 大字号 / 大图 / 大色块 | **标题层级、留白、分隔** |
| 装饰 | 大面积色块、图 | **细线、纹理、边栏、首字** |
| 失败形态 | 太空 | **太挤、没有呼吸、没有层次** |

## 2 排版骨架

### 2.1 版面
- A4 竖版：上下边距 **≥2.2cm**，左右 **≥2.5cm**。装订边可再加 0.5cm。
- 正文行高 **1.5–1.75**（比屏幕阅读更松），段间距 ≥0.5 行。
- **每行 28–40 个汉字**。行太长读者会串行，太短则节奏碎。
- 首行缩进 2 字符 **或** 段间距 —— 二者选一，**不要同时用**。

### 2.2 标题层级
最多 **3 级**。层级之间必须靠**字号 + 字重 + 间距**三重区分，不能只靠字号。

| 层级 | 字号（正文 11pt 时） | 处理 |
| :-- | :-- | :-- |
| 文章标题 | 22–28pt | 居中或左对齐，**标题下方留 ≥1.5 行空白** |
| 一级标题 | 15–17pt | 加粗，上方留白 ≥2 行，下方 ≥0.8 行 |
| 二级标题 | 12–13pt | 加粗或半粗，上方留白 ≥1.2 行 |
| 正文 | 10.5–12pt | 常规字重 |
| 注释 / 出处 | 8–9pt | 弱化色或灰色 |

**禁止**：标题与正文同字号仅靠加粗区分；三级以下还继续分节；
标题跟在正文段落末尾（孤行）。

### 2.3 留白（文档的"锚点"）
- 段落之间必须有**可见的空隙**。整页密不透风是最常见的失败。
- 重要结论、引文、例题周围留白 ≥1.5 行。
- **页脚不要贴底**，留 ≥1.5cm。

## 3 装饰系统（文档版）

**先读通用层「建立稳定的视觉系统」。** 文档场景的判断尤其重要，因为老师经常会说"要朴素一点"。

### 3.1 先判断装饰强度

| 老师的要求 / 内容性质 | 装饰强度 | 具体做法 |
| :-- | :-- | :-- |
| **明确说"纯文本""朴素""黑白就行"** | **零装饰** | 只用排版本身：字号、字重、间距、细灰线。**不加任何图案与色块** |
| 公文、通知、成绩单、试卷 | 极简 | 校名/页眉细线 + 页码。不加图案 |
| 教学讲义、阅读材料 | 轻度 | 页眉细线、章节小标记、灰底信息框、浅色表头 |
| 文学、美文、散文赏析 | 中度 | 首字下沉、引文缩进块、柔和色块、页边细纹 |
| 节日/主题活动材料 | 中偏强 | 主题色系 + 与题材呼应的图形元素（同样遵守 ≤2 类/页） |

### 3.2 常用装饰语言

- **页眉细线**：1px 灰线或主题色细线，最安全也最有效
- **首字下沉**：散文、美文开篇可用；技术文档禁用
- **引文块**：左缩进 + 左侧竖线 + 略小字号，适合引文、金句
- **信息框**：浅色底 + 细边，适合要点提示、注意事项
- **边栏**：左侧窄栏放小标题或编号，营造版面的层次
- **页码与页眉**：正式文档必备，位置全篇一致
- **章节符号**：小图形标记章节起点（如菱形、细线、色块）——**同一份文档只用一种**

### 3.3 按题材选装饰

| 题材 | 装饰方向 |
| :-- | :-- |
| 《春》这类写景散文 | 首字下沉、页边细叶纹、浅草绿底信息框、柔和暖调 |
| 古诗文 | 竖线边栏、朱砂色小标记、宣纸色底、留白充分 |
| 说明文 / 科普 | 页眉细线、灰底知识框、编号小节（**本当是序列时**） |
| 实验报告 | 表头浅色、数据框、步骤编号（真序列） |
| 议论文 | 论点框、引文竖线、克制配色 |
| 通知 / 公函 | 仅页眉线与落款分隔线 |
| 试卷 | 极简：分节细线、答题留白、不装饰 |

### 3.4 纪律
- **一处到位胜过十处零碎。** 每页装饰元素 ≤2 类。
- **装饰不能抢读**：装饰色比正文浅，装饰线比正文细。
- **全篇统一**：第一页用的装饰语言，全篇沿用。
- 老师说"纯文本"，**就真的不加**——此时克制本身就是审美。

## 4 内容密度与呼吸

| 文档类型 | 每页正文 | 留白占比 |
| :-- | :-- | :-- |
| 讲义 / 阅读材料 | 400–700 字 | 25–35% |
| 报告 / 论文 | 600–900 字 | 20–30% |
| 通知 / 公函 | 按需，但**一页不超过 2/3 版面** | ≥30% |
| 试卷 | 题目 + 答题留白 | 答题区 ≥35% |
| 美文排版 | 300–500 字 | **35–45%（这类文档留白就是美）** |

**判断标准**：把页面缩小到 A4 的 1/4 看，如果整页灰糊糊一片、看不出段落，就是太挤。

---

## 5 交付前硬闸门

1. 正文行高 <1.5，或段落之间无可见空隙
2. 标题层级靠字号区分，字重/间距完全没动
3. 每行字数 <28 或 >40 个汉字
4. 页边距 <2cm，或页脚贴底
5. 全篇装饰语言不统一，或装饰元素 >2 类/页
6. **老师要求纯文本却加了装饰**
7. 出现与题材无关的通用图案、图标、光效
8. 标题孤行（标题在页面最底部，正文翻页）
9. 表格跨页断行没有重复表头
10. 关键数据只摆数字、不给判断
11. 占位文未清零
12. 公式、数据、史料、引用系杜撰

> 第 6 条要特别当心：**"少加装饰"比"多加装饰"更常见地是正确答案。**
> 老师要的是合适的呈现，不是热闹。
