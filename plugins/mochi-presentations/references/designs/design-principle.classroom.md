# design-principle.classroom.md · 课堂与答辩场景

> 这份文件是通用法则在**课堂与答辩**场景下的特化。
> 它比通用层更严：课堂投影有距离损耗，答辩现场有评委耐心损耗，两者都不允许"凑合能看"。

## 1 风格 DNA

- **宣纸墨绿，温润而有书卷气**——不做商务蓝的冷硬，也不做政务红金的隆重。Mochi 的气质是"一位讲究的老师"。
- **撑满优先**：内容区元素累计高度 ≥90% 可用高。留白不是主要视觉手段。**课堂课件尤其不允许"一页就几个字"**。
- **层次清楚**：每页至少有「标题 / 主体 / 收束」三层。只有标题和一堆并列短句的页面不合格。
- **证据化配图**：图片必须承担说明功能（实物、示意图、数据图），不做纯装饰。
- **色彩受控**：墨绿主导，赭石只做焦点，蓝紫粉一律不用。
- **内容真实**：公式、数据、史料、引用必须可考。杜撰是红线。

---

## 2 母版骨架

画布 **960×540**。左右安全边距 40，上下 34。页脚条底色只允许 `#F7F3E8` 或 `#FFFFFF`。

| 区域 | 范围（y） | 规则 |
| :-- | :-- | :-- |
| **页眉条** | 0–88 | 墨绿顶条（`#244D3D`）+ 白字标题 28–36px；或浅底 + 墨绿分隔线 |
| **B 内容区** | 88–486 | 高 398px，宽 880px。**累计占用 ≥358px** |
| **页脚条** | 486–540 | 左：课题名 12px 弱化色；右：`NN / TOTAL` 12–14px |

**页眉模式**（全篇锁定一种，不得混用）：
- **H1 实色顶条**：墨绿实底 + 白字，最清晰，课堂投影首选
- **H2 浅底分隔线**：宣纸米底 + 墨绿细线，更轻，适合内容密集页
- **H3 顶条 + 浅水印**：墨绿顶条 + 低透明校园线稿，适合封面/章节页

封面、章节过渡、结束页可省略页脚；其余页必须严格一致。

## 3 色彩与字体

### 色彩

> ⚠️ **先读通用层 §0。色板来自内容，不来自这张表。**
> 下表是"课堂场景没有更强题材信号时"的常用起点。**一旦题材本身给出了色彩信号，就用题材的。**
> 讲《春》用草绿柳黄，讲长征用土黄赭石，讲化学用白瓷浅蓝——**它们不该长一个样**。

**按学科题材选色（优先于下面的默认表）：**

| 学科题材 | 色彩方向 |
| :-- | :-- |
| 语文·写景散文（《春》《济南的冬天》） | 草绿、柳黄、桃粉、雨后灰绿；柔和，可大面积铺色 |
| 语文·古诗文 / 文言 | 宣纸米、墨色、朱砂点缀、青灰；书卷气 |
| 语文·小说 / 戏剧 | 按作品基调定——沉郁用暗褐灰，明快用暖黄 |
| 历史·革命史 / 长征 | 土黄、赭石、旧纸灰、暗红；厚重有年代感 |
| 历史·古代史 | 青铜绿、陶土红、竹简黄 |
| 地理·地形气候 | 等高线绿褐、水系蓝、干旱黄 |
| 生物·细胞遗传 | 浅绿、细胞紫红、透明感白 |
| 物理·力学电学 | 钢蓝、冷灰、白；警示橙做强调 |
| 化学·反应实验 | 白瓷底、浅蓝、透明质感；警示红橙点缀 |
| 数学·函数几何 | 冷白、深蓝、单一高亮；坐标感 |
| 政治 / 德育 | 暖红、米白、金棕；端庄不艳俗 |
| 班会 / 心理 | 暖黄、浅橙、灰蓝；柔和亲和 |

**默认起点（仅当题材未给出信号时）——宣纸墨绿：**

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 背景 | `#F7F3E8` | 宣纸米主底 |
| 主色 | `#244D3D` | 顶条、标题、编号 |
| 辅色 | `#377D6A` | 图表主序列、次级强调 |
| 强调色 | `#D98E3A` | 关键数字、核心结论——**单页 ≤10%** |
| 正文 | `#26352E` | 主体文字 |
| 注释 | `#69786F` | 来源、页码、说明 |
| 浅底 | `#E1EDE3` / `#FFFDF7` | 表头底 / 卡片底 |
| 描边 | `#9BAF9F` | 表格线、分隔线 |

**配色比**：底色 35–55%，主色族 25–45%，浅色 0–25%，强调色 ≤10%。
**禁用**：荧光色；纯黑大底；高饱和撞色铺满 ≥1/3 页面；**与题材无关的色系**。
**反收敛**：连续做的几份课件，配色与字体应当明显不同。上一份用了宣纸墨绿，这一份若题材允许就换一套。

### 字体

| 层级 | px | 字重 | 用途 |
| :-- | :-- | :-- | :-- |
| 封面主标 | 54–72 | Bold | 封面 |
| 章节大字 | 48–64 | Bold | 章节过渡 |
| **锚点数字** | **60–120** | **Bold** | **每页至少 1 个** |
| 页标题 | 28–36 | Bold | 页眉条 |
| 卡片小标 | 20–24 | 600 | 卡片头 |
| 正文 | 18–22 | Regular | 主体 |
| 表格 | 14–18 | Regular / 表头 Bold | 表 |
| 注释 | 12–14 | Regular | 来源、页码 |

字体家族 ≤2 套：`Noto Sans SC` 为主；衬线体仅用于封面主标或引文。
**禁用**：楷体、行书、毛笔体、艺术字、空心字、3D 字、阴影字。

## 4 密度门禁（课堂场景加严）

| 页面类型 | 正文字数下限 | 内容区占用 |
| :-- | :-- | :-- |
| 封面 | 25（中标题 + 副标 + 授课人 + 日期） | ≥55% |
| 目录 | 60（合计） | ≥75% |
| 章节过渡 | 30（大字 + 一句小标） | ≥65% |
| **正文页** | **180** | **≥90%（累计高 ≥358px）** |
| 卡片组页 | 每卡 ≥60，合计 ≥200 | ≥90% |
| 图表页 | 80（含 ≥1 个关键数字） | ≥90%，主图 ≥50% |
| 练习页 | 题干 ≥80 + 留白答题区 | ≥85% |
| 结束页 | 20 | ≥45% |

### 补充规则
- 卡片填充率 **≥80%**：高 ≥300px 卡正文 ≥80 字，高 ≥380px 卡正文 ≥110 字。
- 单行多卡**等高**；卡尾元素锚底；兄弟卡高度差 ≤8px。
- 卡内 padding：上下 14，左右 ≥18。正文必须软换行，**禁止溢出**。
- 文字对比度 **≥4.5:1**：墨绿底放白字，宣纸米底放深墨绿。
- 正文页至少复用 **3 类组件**、至少 **3 个内容层次**。
- 常规内容页留白 **≤30%**。练习页的答题留白不计入此限（那是功能性留白）。

### 页面信息下限
- **练习页**必须留出 ≥35% 的空白答题区，否则学生无处下笔。
- **公式页**每个公式下方必须有一句中文说明它在说什么。
- **表格页**表占 ≥70%，且必须有结论行。

## 5 组件族

- **标签 / 编号**：墨绿编号方块、浅绿药丸、赭石高亮标签（赭石受 ≤10% 配额限制）
- **标题条**：墨绿标题条、底部强调条、核心结论条（**结论条单页 ≤1 条**）
- **卡体**：默认浅描边卡；凸显单卡用柔和阴影卡；**墨绿实色卡单页 ≤1、全篇 ≤3**
- **流程连接**：节点串、胶囊步骤、箭头——用来把多卡页串成整体
- **数据强调**：KPI 三联数、表格高亮、进度环、引文块

卡片填充只允许白 / `#FFFDF7` / `#E1EDE3` 或低纯度浅色；**禁止渐变填充作卡背景**。

### 卡内四段骨架
常规卡优先包含：**S1 标题条 → S2 主体内容 → S3 关键数据或例句 → S4 尾部标签**。
S1/S2/S3 必填，S4 锚底。内容太少时**改版式，不要用空白撑高**。

## 6 页面类型规则

### ① 封面
标题、副标题、授课人/单位、日期。可加页眉条或大片留白 + 中央标题。
**禁止**：党政红金、印章、烟花、人物大头照、无意义的装饰几何。

### ② 目录
3–6 个条目，编号 + 标题，可有引导句。
**禁止**：圆球编号、书法数字、英文比中文抢眼。

### ③ 章节过渡
全篇锁定一种样式：大数字 + 章节标题 + 2–4 个要点提示。
**禁止**：与封面雷同、满版色块、`PART 02` 字样泛滥。
> ⚠️ 同时部署 1–2 页以上的课件，章节过渡页**必须是整页重页**，不能做成小标题条。

### ④ 正文页
四种基础版式，按内容选：
- **4a 左标题条 + 右正文**（60:40）——概念定义
- **4b 卡片组**（2–3 卡）——并列要点，**全篇 ≤3 页**
- **4c 非对称双栏**（65:35）——对比论证
- **4d 大图 + 文字叠层**——实验、案例、实物

多卡页必须有**双重锚定**：一种物理连接（箭头 / 共享外框）+ 一种共享锚点（标题条 / 底部结论条）。

### ⑤ 数据与图表
主图 ≥50% 内容区，上方必须有引导问题或结论条，图旁必须有 **≥1 个关键数字**。
图表配色固定：主色 `#377D6A`、辅色 `#D98E3A`、第三色 `#5E7DA8`。
表格：墨绿表头 + 浅斑马纹，关键格可浅赭石高亮。

### ⑥ 练习与例题
**题干区（≤60%）+ 答题留白（≥35%）+ 提示条**。
**禁止**题目与答案同页出现（除非是"答案页"，且必须紧跟题目页）。

### ⑦ 结束页
收束句 + 落款。可用与封面呼应的版式。
**禁止**：烟花、金装饰、印章；**禁止**只写"谢谢观看"。

## 7 最终硬闸门

出现以下任一情况，**必须返工**：

1. 内容页未撑满：累计高 <358px 或留白明显过大
2. 某页无视觉锚点，所有元素大小趋近
3. 正文字号 <18px，或页标题 <28px
4. 赭石 >10%，或出现禁用色
5. 卡片缺 S1/S2/S3，或卡内出现明显空白带
6. 墨绿实色卡超限（单页 >1 或全篇 >3）
7. 渐变作卡背景
8. 正文页组件 <3 类或层次 <3 层
9. 多卡页缺双重锚定，呈散碎卡片堆
10. 配图风格混杂，或使用 3D / 卡通 / 营销插画
11. **文字溢出卡片、被裁切、断词异常、对比度 <4.5:1**
12. 页眉模式 / 页码位置全篇不一致
13. 图表缺主图、缺洞察或缺关键数字
14. 占位文未清零
15. 公式、定理、数据或引用系杜撰或无据可查
16. **未做视觉回看**：生成或修改后没有调用 `mochi_ppt_render` 亲自看过

> 第 11 与第 16 条**只能靠渲染回看发现**。第 11 条这类"结构完全正确但视觉已经坏了"的问题
> 是 AI 生成课件最常见的隐性缺陷——文字被裁掉、元素压在一起，在 XML 里根本看不出来。
