# 第八版画面核对

已逐帧查看开场定位、四款配色、课件、日常功能、信箱、七个桥接段的关键时点与结尾；另从实际编码的开场3.8秒、结尾6.5秒抽帧核对。

修正记录：
- 课件/交付/信箱中的原浅色光层削弱主题区分：减弱光层，保留真实界面本身。
- 背景继承导致原DOM前景可能变色：先冻结原前景色，再设置舞台主题。
- 桥接0的三点靠近成员名、桥接2的环绕动作靠近输入控件：改到两屏之间的上方留白。
- 桥接5的角色靠近发送键：入场、停留与退场均改到窗口上方留白。
- 编码扫描发现162.47–164.20秒近静止：在学生章节29.2–31.5秒增加从通知到回执的镜头引导，保持原播放速度和时长。
- 接信转场右上Logo与原标题相邻：将这一处Logo移至左上留白。
- 绿色Mo和绿色背景融在一起：四色展示角色后方加浅色光场，不修改角色色值或原生UI。

自动几何检查使用866个时点；原引擎缓存的隐藏节点属性可随历史变化，比较时排除display=none和r=0的不可见圆，实际可见形状在乱序seek后相同。没有为通过检查更改产品引擎。

这些检查只覆盖本轮后期变更；不代替用户审片，也不将历史功能演示变成全项目功能测试。
