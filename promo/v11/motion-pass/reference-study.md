# K2.6 / K3 第二轮镜头研究与第六版落地

参考是桌面真实视频：Kimi_K2.6_发布并开源.mp4（43.946667秒）和Kimi_K3_智能的新前沿.mp4（56.704秒）。通览分别每1.8秒、2秒抽帧；对K3约23–27秒与K2.6约32–36秒每0.2秒观察一次。抽帧证据在evidence/reference-study，未将参考片图像放入Mochi成片。

## 观察到的事实

- K3约23–27秒，骑马场景先保持内部运动，随后整个场景缩回纸张/素材组成的环境；相机继续移动，另一件3D作品进入主位。前后画面曾同时在场，并非黑场换页。
- K2.6约32–36秒，网页、后台列表、图表、移动端等围绕主成果组成一组。画面从局部任务拉远到成果群，尺度变化告诉观众它们属于同一件事。
- K3纸张与作品背景多次延续；K2.6沿用同一个网站继续加功能，因此视觉变化有对象依托。
- 本机参考视频不是Github的16秒k3-promo示例，不能混为一条片。

## 合理判断与改法

原Mochi七个交接共用相似的两窗口缩放模板，改变文字位置仍不足以建立各自的意义。第六版只重写六个转场，不改变功能演示中的产品界面，也不伪造新能力。保留叮咚投递这一处已有明确因果的动作。

|连接|空间动作|对应的叙事目的|
|---|---|---|
|想法→团队|横向同行，下一场提前出现|从个人扩展到协作|
|团队→成果|拉远到真实课件群，再推进主成果|把过程和交付放在同一空间|
|成果→模型|纸面折起，圆形视窗打开|从纸面转入可交互场景|
|信箱→校园|原信箱内容折为信封，跨越两端|信件确实来自上一画面|
|叫人→查人|收拢外围，展开对话视窗|从跨端协作回到一个问题|
|协作→记忆|前景向上翻过，下一场从下方接上|今天的事情成为明天的上下文|

动态课件仅用于成果、建模、记忆的背景，顶部渐隐给标题留出干净阅读区。其余镜头用移动的浅色空间，让信箱和查人不被无关数学课件干扰。Mo使用原角色球体，不新增吉祥物。未采用重复卡片旋转作为全部转场。

## 验证边界

逐帧时间轴可以验证时点、字体和连续性；不能据此断言原片使用了什么软件或认为艺术效果已经得到用户认可。输出仍供审片。章节时长不变，语音、拍题、课表仍不加入。本轮音乐重点重新映射到新的转场动作，封面和三音轨版本继续保留。

渲染复核发现：自定义字体名Serif与CSS通用族同名，被HyperFrames规范化为Inter并联网获取；改为MoSerif以使用原本地Noto Serif字体。受影响的折纸模型与记忆镜头重新渲染。此问题来自实际编译日志和规范化源码，不推断为产品字体错误。
