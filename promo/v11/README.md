# Mochi V11 工作目录

目标仍为4–5分钟全功能影片。当前没有完整版；内部运动测试不可作为交付。

- `Kimi-K3-逐镜研究.md`：桌面56.7秒K3片逐镜证据与280秒影片规划。
- `motion.js` / `motion.css`：确定性时间轴辅助层、屏幕独立鼠标、统一比例、点击光环、位置衔接、逐字字幕。产品组件不重绘。
- `motion-review/`：16秒内部转场与鼠标检查，只是工程检查工具，无配乐；不是新增短版宣传片。
- `export-lan-evidence.mjs`：只读隔离演示两端持久化数据，导出白名单字段；原身份私钥、配对密钥、信封签名不进入浏览器资产。
- `lan-evidence-report.json`：叫人/预约回复的发送确认、接收身份、正文一致、教室已读及回执时间匹配结果。仅证明历史演示记录闭环，不证明当前在线或新录制完成。
