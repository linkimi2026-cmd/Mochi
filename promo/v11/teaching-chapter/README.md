25 秒，2560×1440、120 fps，3000 帧，AAC 双声道。当前输出 `output/teaching-artefacts.mp4` 仅供内部拼接，不是独立交付，也不代表全功能影片完成。

画面顺序：实际 PPTX 封面与流程页展开 → 第 2 页文字内容 → 同页修订为可编辑折线图 → 课件、教案 PDF、成绩图表三列反向滚动 → 同一课件回到前景，折纸飞向下一章节。标题逐字运动与退场，背景作连续视差移动。主画面全程使用 Mochi 实际工具产物；页面本身没有被重新设计成虚构软件 UI。

`revise-lesson.mjs` 调用项目原有 `revisePresentationBundle`，用原课例 y=0.5x+2 计算五个数据点，修订同一份六页课件的第二页。PPTX ZIP 含原生 chart1.xml；其余五页的语义哈希保持一致。这里是直接调用实际产品工具，不是新录到的 AI 聊天，不要把此前模型自动播放请求的失败录屏和本段接成同一成功任务。

原始页和修订页来自各自真实 PPTX 的 LibreOffice 预览 PDF，以 2560×1440 渲染。教案是已有文档 PDF；它不是试卷，不计作试卷整理功能完成。成绩图表直接读取现有生成 SVG，保留几何、数值、标签；后期只调整弱对比灰字、字体回退和柱子入场。三列滚动是成果编排，不是新产品界面。
