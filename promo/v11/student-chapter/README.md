## 记录与画面

| 章节时间 | 内容 | 证据解释 |
|---|---|---|
| 0–7 | 收到小林预约 | 从真实记录恢复收到后、回复前状态；原请求组件，历史重放 |
| 7–13 | 同位置显示教师回复 | 原请求退场，原回复状态接续；没有编造输入操作 |
| 13–19 | 教师与教室同屏 | 同一条回复对应两端记录，原组件分别展现 |
| 19–24 | 提问、补做 | 小陈尚未回复、小周未处理，保持事实 |
| 24–29 | 叫人通知 | 已核对通知内容；本章尚不含教师发起操作 |
| 29–33 | 已读确认与撕下 | 固定比例鼠标点击实际按钮；原确认组件提取至左侧，不遮挡通知；420ms原撕纸几何 |
| 33–36 | 已读归档 | 教室已读状态 |
| 36–43 | 回执接力 | 教室缩为左侧上下文，教师原回执成为主画面 |
| 43–50 | 成果汇合 | 已展示记录回归，接向校园章节 |

固定标注“真实演示记录 · 原界面组件重放”。片内无网络请求，不重新发送校园通知。没有把已读说成事项办结。

## 折纸与连续空间增量

用户追加方向后，13.15秒真实回复组件的内容副本折起，变成纸飞机沿弧线飞往教室，接收界面在15.25秒开始展开；36.15秒已读记录折为信封，将对应回执送回教师端。两者都是后期意象，原网络事实由两端记录核对证明，不能把视觉飞行当网络过程。

背景由三段相接的纸张空间组成，教师暖纸色、教室淡青色、校园浅绿，前/远景分别以1.18和0.86的速度响应空间移动。阅读时段保持稳定，跨端交接时移动。背景无产品控件、无虚构数据；原生组件保持前景。移除了首轮低对比的装饰大字，避免混淆信息层级。
