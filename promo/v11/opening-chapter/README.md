输出 `output/opening-presets.mp4`；记录 `evidence/export.json`。初次导出已核：18.000000秒、2560×1440、120fps、2160帧、AAC48kHz双声道；全片FFmpeg解码通过，并查看逐秒实际导出接触表。初次审片修正标题遮住输入控件、点击早于真实选择、出场时发送按钮被裁掉的问题。最终小黑边裁切后再次导出18.000000秒/2160帧/10,446,106字节，全片解码通过；3.5–6.5秒边界按每秒两帧实看，圆角黑边已去除。
