# Mochi V9 功能演示

规格：2560×1440、120 fps、4分46秒。26个连续场景，对应30组功能。

全片使用项目源码支持的功能编写 HTML/CSS/SVG 场景，再由 GSAP 时间轴逐帧渲染。无桌面、菜单栏、Dock 或其他应用录屏。人物、班级和结果均为示例数据；场景设计是功能演示，不是所有后端流程的运行验收。国庆场景明确标注10月1日演示日期。

## 编辑与重渲染

- `index.html` 是可直接渲染的完整场景；`build-film.py` 是生成源。
- `scenes.json`、`功能覆盖与来源.md` 和 `feature-coverage.json` 列出内容、时间码、源码依据。
- `Mochi_V9.srt` 是外置字幕，画面已内置场景说明。
- `assets/score.wav` 是本项目代码合成的背景音乐，无配音；`score.py` 可用 Python 3 + NumPy 重新生成。
- 技术版本：Node 24.19.0、HyperFrames 0.8.36、GSAP 3.15.0。依赖由 package-lock.json 固定。

在源码包目录运行 `npm ci`，需要改内容时运行 `python3 build-film.py`，再运行 `npm run check` 和 `npm run render`。渲染器首次运行可能下载浏览器。生成影片位于 `output/Mochi_V9_2K120_4m46s.mp4`。

渲染使用4个捕获工作线程并直接编码，避免把34320张未压缩帧写入磁盘。不修改分辨率或120 fps。较低内存机器可把 `render.sh` 的 workers 改为1，仍保留逐帧120 fps输出。

## 维护与素材

场景集中在一个生成器里，没有为此迁移产品框架或增加生产依赖。对 Mochi 产品功能的升级应先核对实际源码，再同步对应场景及覆盖表。源码包不包含账号、用户聊天、私有教材、演示环境凭据和原始录屏。
