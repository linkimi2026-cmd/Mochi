# Mochi · 102 秒 2K 发布会版

画幅 2560 × 1440，60 fps。画面以真实产品界面、源组件重演和实际生成成果组成。源录屏帧率低于 60 fps 的部分不会因此被宣称为原生 60 fps 录制。

## 事实范围

- 已核实：课件、试卷、交互模型、校园网页、学生查询、人工审批、FIND 资料查找、LAN 文件接收与预览的现有实测材料。
- 用户确认：Windows 一体机全部功能实测正常。本片未新增 Windows 硬件录屏，不把本机双进程说成两台 Windows 实机。
- 源界面重演：输入、过程节选、学生查询、审批、老师 ASK 回应；这些镜头没有再次提交后端请求。已保留在片内简短注明，不用重演制造额外成功记录。
- FIND 返回的是资料已找到的文本回音；随后教室文件接收是另一项真实 LAN 任务，不能说 FIND 回执附带文件。
- 总体方案中记忆、学生端终态等设计，不凭方案文字宣称已独立完成拍摄或验证。102 秒展示的是已具备证据的主要特色，不代表每个设计条目都有完整演示。

## 动效依据与维护

采用已审计的 HyperFrames 0.8.36、GSAP 3.15.0；用原有时间轴、SVG、transform、clip-path 与媒体寻帧。Kimi 参考片可观察到成果聚合、聚焦展开和共用元素转场；其内部具体制作软件未确认，不声称用了 GSAP。

工程仅在 promo/v4 与独立构建脚本内维护，不改变 Mochi 的执行、权限或业务行为。标题动画只作用于编辑文案，产品标签保持原样。所有分镜切换为连续时间轴，不能只凭静止抽帧推断动态观感完全通过。

## 音轨

按用户要求，审片版使用其提供的 Kimi K2.5 视频音轨，剪至 102 秒并作交叉淡化与响度处理。该素材的公开传播授权未核实。另行提供沿用已核 Mixkit 授权音乐的网络传播备选版；保留许可正文，不将音乐独立分发。

最终视觉落点更新：结尾文案为「连接老师，连接课堂，连接整个校园。」视觉引导仅使用鼠标轨迹虚线与同轨移动光点，不出现实线引导；鼠标、光点和虚线揭示共用 SVG 路径进度，避免单独运行的动画与主片脱节。文字采用原生字形遮罩进入与退出，不用随机字符替换或乱码式转场。
