## 技术参数

- 合成：`index.html` 单文件（2560×1440，`data-composition-id="mochiV7"`，62s，60fps）
- 时间轴：GSAP paused timeline 挂 `window.__timelines.mochiV7`；无 `Math.random`，逐帧渲染确定性
- 色板：V6 发布会同源（纸白 #faf8f2 / 墨 #283d35 / 品牌蓝 #3F5B99 / 绿 #2f7a4f / 橙 #b4552d / 暖黄 #d5a54e）
- 字体：NotoSansCJKsc Regular/Bold + NotoSerifCJKsc SemiBold（本地 `assets/`，许可随附）
- 配乐：Mixkit Tech House（`assets/music.wav` 硬链自 v6/assets，取 0–62s 连续段，不循环拼接；许可随附）
- 形象：OrbCompanion 为 SVG 手绘（球+面前小电脑+双手敲键盘），符合「禁止用纯球体冒充 Mochi」的品牌裁定

## 复现

```bash
cd promo/v7
npx hyperframes lint .          # 0 error
npx hyperframes render --fps 60 --quality high --workers 1 \
  -o ../output/Mochi_62秒_MotionGraphics_V7.mp4
```

## 边界

- `assets/` 内 music.wav 与 gsap.min.js 是指向 v6/assets 的**硬链**（同文件系统，不占双份空间）；字体为软链
- 输出若用其他 fps 需同步修改 `data-fps`；改文案直接编辑 `index.html` 内文本节点
