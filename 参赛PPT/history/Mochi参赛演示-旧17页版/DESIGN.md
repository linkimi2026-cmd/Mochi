## 2. 颜色系统

**色彩池（严格 4 个 hex）**：

| 角色 | Hex | 用途 |
|---|---|---|
| **主色 · 深墨绿** | `#16211d` | 全篇背景；深色大色块 |
| **辅色 · 鼠尾草绿** | `#45584e` | 卡片底、分隔线、次级块、深色渐变终点 |
| **强调色 · 焦糖** | `#e8b34b` | **只出现在视觉焦点**：巨型数字、审批卡描边、页脚圆点、CTA |
| **中性 · 暖米白** | `#f5f2e9` | 全部文字、浅色块、描边 |

> 次级文字统一用 `#f5f2e9` + `opacity 0.45~0.7` 表达，**不引入第 5 个 hex**。

**色彩面积分配**：

| 色彩角色 | 面积占比 | 说明 |
|---|---|---|
| 主色（深墨绿） | 50–60% | 背景铺底 |
| 辅色（鼠尾草绿） | 20–28% | 卡片 / 分隔 / 次级块 |
| 强调色（焦糖） | **≤ 10%**（Hero 页可到 15–20%） | 只落在焦点元素上 |
| 中性（暖米白） | 剩余 | 文字与描边 |

**色彩节奏**：至少 2 页比例显著不同——第 13 页（巨型数字页）强调色达 18%，第 02 页（目录）强调色 ≤ 3%。

**渐变与半透明方案**：

| 用途 | 值 |
|---|---|
| 深色页背景渐变 | `linear-gradient(135deg, #16211d 0%, #1f2b26 100%)`（`#1f2b26` 为 `#16211d` 与 `#45584e` 之间的插值，**不新增色彩池**） |
| 产品截图蒙版 | `rgba(22, 33, 29, 0.55)`（保证暖米白文字可读） |
| 封面 / 结束页蒙版 | `rgba(22, 33, 29, 0.68)` |
| 卡片底 | `rgba(245, 242, 233, 0.05)` + `1px solid rgba(245, 242, 233, 0.12)` |
| 卡片浮起 | `boxShadow: '0 8px 32px rgba(0,0,0,0.35)'` |
| 审批卡聚焦 | 焦糖色 `3px` 描边 + 外发光 `0 0 0 8px rgba(232,179,75,0.18)` |

## 4. 信息密度与留白

| 页面类型 | 最少元素 | 正文字数下限 | 图数下限 | 主视觉占 B 区 |
|---|---|---|---|---|
| 封面（01） | 主标题 + 副标 + 主视觉 | 30 | 1 | ≥ 40% |
| 目录（02） | 4 条目 + 引导句 | 130（合计） | 0–1 | — |
| 内容页 · 单主题 | 标题 + 正文 + 主视觉 | **180** | 1 | ≥ 30% |
| 内容页 · 卡片组 | 标题 + 引导句 + 3 卡 | **每卡 ≥ 100** | 0–N | — |

**默认留白上限**：常规内容页 ≤ 35%；封面 / 章节过渡 / 结束页不受限（本 PPT 章节页留白约 48%）。

**容器填充率**：卡片内实际内容垂直占用 ≥ 卡片高度 85%；卡片尾部元素（引文条 / 标签条）用 `marginTop: 'auto'` 钉底；同行兄弟卡的三段（标题块 / 正文块 / 尾部）y 轴等高对齐，误差 ≤ 16px。

## 5. 配图系统

| 等级 | 本项目用法 | 最小尺寸 / 占比 |
|---|---|---|
| **L1 · 主视觉** | **真实产品界面截图**（本项目全部 L1 均为实拍截图，非生图） | 占 B 区 ≥ 40%；常见 620×420 / 半屏 |
| **L2 · 支撑图** | 次要界面截图（如审批闭环小图） | ≥ 280×180 |
| **L3 · 母版徽标** | 焦糖小圆点（直径 10px），固定在 C 区左侧，**全篇位置一致** | ≤ 64×64 |

**配图策略声明（重要）**：

1. **本项目 L1 一律使用真实产品截图，不使用 `ImageGen` 生图**。理由：用户明确要求「图片取自于 Mo 的真实页面界面」——真实截图的说服力是生图无法替代的（用户显式指令优先于通用法则的"具象场景优先生图"）。
2. **允许 SVG 的元素**：多 Agent 协作网络架构图、章节页的抽象纹样、巨型数字、进度环、装饰细线。
3. **截图使用纪律**：所有截图必须**裁切掉调试痕迹**（报错弹窗、证据板标记、英文 fixture 占位文字）；截图统一加 `1px solid rgba(245,242,233,0.12)` 描边与 `borderRadius: 12px`；同一页出现两张截图时，必须**一张为主（大）一张为辅（小）**，禁止等权并置。

**素材清单与黑名单**：见 `STORY.md` §素材可用性备忘。**黑名单中的文件一律禁止使用**。

## 7. 通用禁忌（逐页制作时逐条核对）

- ❌ 同一页出现 ≥ 2 套主色板；引入第 5 个 hex
- ❌ 高饱和撞色铺满 ≥ 1/3 页面
- ❌ 全篇每页色彩比例雷同（差异 < 10%）
- ❌ 把产品截图缩小成 200×70 塞进标题块右侧当装饰
- ❌ 连续 ≥ 2 页使用等宽卡片横排（本 PPT 已规划 0 次）
- ❌ 截图保留调试痕迹（报错弹窗 / 证据板标记 / 英文 fixture 文字）
- ❌ 使用 `STORY.md` 黑名单里的任何文件
- ❌ 在 15 页展开产品功能讲解（该页由同学负责，仅占位）
- ❌ 出现内部工程代号与实现细节（快照哈希 / CI 配置 / 代码级术语 / 内部 agent 代号）
- ❌ 编造数据。所有数字必须来自项目文档或 `WORKLOG.md` 已有记录
