# STORY.md · Mochi 参赛演示

## ① 用户意图对齐

**目标受众**：**嘉祥教育集团 AI 创意实践大赛（高中组）** 的评委与现场观众。

**核心目标**：讲完后，希望评委相信三件事——

1. **Mochi 不是套壳 Chatbot**：它跑在真实的 Agent Harness 内核上（DeepSeek 官方开源内核，MIT 协议），有完整的工具调用、子代理、审批门、会话轨迹；
2. **Mochi 已经能在真实校园里用**：Windows 与 macOS 双平台安装包均已交付，老师双击即用；
3. **Mochi 解决的是真问题**：教师的时间被校园事务切碎。

**PPT 长度**：**16 页**。Hero 页 4 页（25%），符合 20–30% 配额。

**视觉调性**（5 个词）：**产品发布会 · 沉浸深色 · 产品即主角 · 文字极简 · 品牌一致**

> **关键决策（2026-09-12 用户裁定）**：整份 PPT 按**产品发布会**（Apple / 小米发布会那种）的调性来做——
> - 深色沉浸底，超大标题，**每一页都有真实产品界面出现**（用户原话：「本尊要出现」）；
> - 沿用 Mochi 自身品牌配色（鼠尾草绿 / 暖米白 / 焦糖），让幻灯片与产品同源；
> - 文字服务画面，不做信息墙。

**内容边界**：

| | 内容 |
|---|---|
| **必讲** | 真实 Harness 底座 / 插件体系 / 人在环审批 / 数据不出校 / 双平台真实交付 / **Mochi 自己生成的内容** |
| **不讲** | 内部工程细节（快照哈希、CI 配置、代码级实现、内部代号） |
| **禁碰** | **产品功能讲解与现场演示环节**——由同学负责，本 PPT 仅保留一个交接页 |
