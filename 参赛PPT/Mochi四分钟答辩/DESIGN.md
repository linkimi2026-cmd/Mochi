# 四分钟答辩设计

总长 4 分钟：80 秒真实产品视频，随后五页 25/30/35/32/35 秒讲述，结尾 3 秒。

主线：嘉行联的需求探索 → Mochi 的原创适配层 → 人机反馈中的方向判断 → 有边界的默契。

视觉：暖米白、校园绿、焦糖色。主标题与正文使用黑体，关键句与品牌使用宋体，避免整篇同一种字重。真实历史网站与 Mochi 实录并列展示；三层结构与反馈循环保持可编辑。

素材：网站图片取自联动计划 qa-evidence 中 2026-08-20 的真实历史截图，它不是首版页面的证据；Mochi 画面来自现有实录；Mo 来自既有产品品牌画面，不重新生成形象。

工程：`scripts/build.mjs` 生成页面；`scripts/media.py` 封装原始 MP4、基础动画与转场；`scripts/finalize.mjs` 校验输出。`.build/` 只保存中间产物，`output/` 中的 PPTX 是比赛使用文件，两者均由 Git 忽略并通过完整交付目录分发。旧17页演示仍保留作历史素材，不作为本轮答辩入口。

本轮修订：第一页增加学生流转的信息同步痛点与教师工作分散的延伸动机；第二页改为桌面/界面、Agent 内核、校园业务后端三列技术架构。事实核对来自桌面依赖、品牌 React 源码与项目关系文档。讲稿仍按 30/40/45/42 秒安排。修改页渲染已检查，未改开头媒体和结尾动画逻辑。

2026-09-16：架构页后新增「教师端与教室端互联」，明确标为未来规划。沿用米白、校园绿和焦糖色的可编辑文本布局；表达学生查询错题、AI 问题讲解、答疑预约往返，以及按课表、偏好和授权计划提前准备 APP。讲稿重排仍以四分钟为目标，结尾动画相应改为本页第 35 秒显示品牌。
