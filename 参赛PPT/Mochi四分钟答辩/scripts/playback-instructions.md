

1. 打开 output/Mochi_四分钟答辩_内嵌视频.pptx，选择“放映 → 从头开始”。
2. 点击第一屏的视频画面开始播放。视频已内嵌，不依赖网络或外部视频路径。80 秒结束后手动进入下一页。
3. 后面四页按讲稿手动翻页。最后一页进入后自动计时，约 42 秒退去说明文字，显示 Mochi 品牌句，停留 3 秒结束。
4. 编辑模式会同时看到最后一页的前后两个动画状态，这是同页分时显示；实际效果请在放映模式查看。

已验证：本机 macOS WPS 的视频点击播放、结尾进入状态与 42 秒品牌收束；PPTX 结构、五页数量和内嵌视频哈希通过检查。最后一页静态重叠提示属于前后两个动画状态，不是同屏排版。

尚未验证：比赛现场 Windows WPS 版本与字体环境。使用 Heiti TC、Songti SC；现场电脑如替换字体，需提前排练检查换行。四分钟为讲稿目标时长，翻页与口头速度由讲者掌握。
