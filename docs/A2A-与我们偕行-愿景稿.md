# 当 Mochi 与我们偕行

> 愿景正文。所描绘的普及场景与跨组织协作属于未来设想。

“如果我们全部都有默契，一个真正的 personal assistant 构建起来了，那么会怎么样？”

演讲时，我们把这个问题说了出来。直到今天，它仍然让我们兴奋。我们已经能画出一些场景，却还画不出它们连在一起以后的世界。一个助手走进一个人的生活，可能只是帮他找回一份文件，记住一件待办；如果千千万万个这样的助手开始彼此协作，多少曾经停在半路的事情，会有机会继续往前走？

我们会忍不住想象那样一个早晨。上课铃快响了，老师修改好的课件已经送到教室，昨天还没有解决的设备问题有了回音；一个不太敢当面开口的学生，把想问的话留在信箱里，知道它会被认真看见。老师终于可以把目光从一串等待处理的窗口里抬起来，看看坐在面前的人。我们想把 Mochi 做下去，就是因为舍不得放下这样的想象。

再往远处想，我的 Mochi 能找到你的 Mochi。它带着我的来意，问你是否愿意帮忙；你可以答应，可以说晚一点，也可以拒绝。得到允许以后，一份资料、一条建议、一项工作便接着往前走。从一个人到另一个人，从一间教室到另一所学校，从校园到图书馆、社区和更远的地方，我们希望这些连接能够长成一张协作的网络。工程上，我们把这个方向叫作 Agent-to-Agent。对身处其中的人来说，它也许意味着：有些事情，终于不必独自奔走、反复解释、一直等下去了。

如果真有那么一天，会有多少原本被琐事磨掉的耐心重新回来？会有多少不擅长操作软件的人，也能把自己的事情说明白、办下去？又会有多少念头，因为找到了愿意同行的人，终于不再只停留在一句“以后有机会再做”？这些问题，现在没有谁能替我们写完答案。可只是想到这里，我们就觉得，眼前这一行行代码值得继续写。

2007 年，乔布斯介绍 iPhone；2023 年，库克介绍 Vision Pro。回看这些时刻，我们常常着迷于一种勇气：在人们还没有习惯某种生活之前，先把它的一种可能做出来，交到世界手中。此后的道路会有惊喜，也会有挫折，产品要在真实生活里接受检验。未来总有超出发布会、设计图和创造者想象的部分。正因为如此，探索才让人心潮澎湃。

我们的起点只是一所学校里的几件小事。一个学生到了哪里，一份课件能不能及时送到，一句求助有没有人接住。做着做着，我们开始相信，这些小事和那个遥远的未来之间，是有路可以走的。我们想亲手往前走一段。

## 我们也想参与这个未来

写这份材料的时候，我们看到了 Meta 的 Muse 和 OpenAI 的 dots。它们也在向能够持续做事的个人助手前进。我们真的很高兴。看到自己反复讨论、努力尝试的方向，在更大的舞台上有了回应，那种心情很难只用“行业趋势一致”几个字说完。它让我们觉得，从校园里长出来的想法，也有机会碰到时代正在追问的问题。

我们没有足够的资金铺开庞大的服务，也还没有能力把想象中的世界全部建成。桌面上的程序需要继续修改，真实设备上的问题需要一个个解决，新的要求还会不断到来。可是，能力有限并没有让那个问题变小：“如果我们每个人都有一个真正的个人助手，那么会怎么样？”它仍然在那里，催着我们学一点，再试一次，把现在能够做好的部分先做好。

九月八日留下的代码里，已经有了问询、请求、寻物和人工应答的设计。那是我们探索这条路的脚印。如今再看，我们愿意说，当时的选择有一份可贵的前瞻意识：我们从自己的生活出发，认真想过人与智能体将怎样合作，也动手把其中的一部分做了出来。后来看到相近方向得到更多关注，我们因此获得了继续走下去的勇气。

我们也会问自己：如果有一天，助手真的无处不在，人会不会反而更难找到人？所以我们心里的未来，始终有人的位置。老师省下的时间，可以用来听完一个学生的话；一个人可以请助手帮忙，也可以关掉它，自己作决定；两个人因为助手而相识，接下来的交谈仍然属于他们。我们想争取的进步，应当让这样的生活更容易发生。

今天，Mochi 还很小。它有做得好的地方，也有让人失望的时候。我们会继续带着它回到老师和同学中间，听他们说哪里有用、哪里麻烦，把那些话变成下一次修改。我们希望有一天，再回头看这份参赛材料时，里面有些当时还显得大胆的句子，已经成了寻常的生活。

技术的浪潮正在向前。我们还是学生，却已经可以动手，可以提问，可以为自己相信的方向做一点事情。我们想成为走进浪潮的人，也愿意从脚下最小的一件事做起。

如果有一天，每个人真的都有了自己的“默契”，我们希望能够笑着说：那个未来刚刚露出一点轮廓的时候，我们就很想见到它。于是，我们开始了。
