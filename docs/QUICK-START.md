# Mochi 快速开始

> **status**: active
> **last_verified**: 2026-09-14
> **verified_by**: Codex（安装包路径与产品操作逻辑；本轮未重装 macOS 包）

## 1. 选择安装包

| 电脑 | 文件 | 使用方式 |
|---|---|---|
| Windows 10/11 x64 | `02-Windows-x64/mochi-windows-x64-34728914066.zip` | 先解压，再运行归档内的 `Mochi-Setup-*.exe` |
| Apple 芯片 Mac | `03-macOS/Mochi-0.1.0-mac-arm64.dmg` | 打开 DMG，把 Mochi 拖入“应用程序” |
| Intel Mac | `03-macOS/Mochi-0.1.0-mac-x64.dmg` | 打开 DMG，把 Mochi 拖入“应用程序” |

安装前可用 `05-校验/SHA256SUMS.txt` 核对文件。Windows 安装包和 macOS DMG 当前未做代码签名；系统出现来源提示时，应先核对 SHA-256，再从系统提供的“更多信息/仍要打开”入口继续。

## 2. 观看宣传片

当前参赛交付选用 `04-宣传片/Mochi_80秒_2K120帧_V5.mp4`。媒体参数已核对为 80 秒、2560×1440、120 fps。磁盘上另有 100 秒 V6 历史导出，但本交付目录按用户选择不收录。

## 3. 第一次进入 Mochi

1. 选择一个本地文件夹作为默认工作区。
2. 比赛演示时选择“全部允许所有权限访问”，让 Mochi 可以在工作区中生成和修改文件。
3. 切换到“工作模式”后再发送课件、文档、试卷、建模或网站任务。
4. 生成期间保留进度反馈；产物出现后打开检查。
5. 教师工作台遮挡主界面时及时关闭，再继续下一项演示。

## 4. 建议先试的任务

```text
为初中数学“三角形基础”制作一份简洁、美观、可直接授课的课件，保存到当前工作区。
```

生成完成后再试文档、试卷整理、简单三角形交互模型或网页任务。演示中优先选择短任务，避免把完整生成等待时间全部播放给评委。

## 5. 校园协作功能

校园查询、查找学生、沟通老师、Agent to Agent 和批准放行依赖“联动计划”的校园后端与演示账号。账号由该项目受管配置提供，本交付包不存放明文密码。涉及批准或状态修改时，按界面完成授权确认。

## 6. 当前验收边界

- Windows 一体机全部功能正常：项目方已确认。
- macOS arm64 与 x64：本轮确认安装包文件和构建记录存在，没有重新在全新机器安装。
- 源码 ZIP：本轮执行大小、敏感信息、逐文件哈希和 ZIP 完整性检查。

更多证据与限制在 `01-源码/Mochi-参赛源码包-2026-09-14.zip` 中的 `docs/DELIVERY-LEDGER.md` 和 `参赛材料/真机验收记录.md`。

从项目根目录进入 `01-Mochi-参赛交付包-2026-09-14/`，打开 `06-答辩PPT/Mochi_四分钟答辩_内嵌视频.pptx`，使用 WPS 从头放映并点击视频开始。随后按同目录讲稿手动翻页，总目标 4 分钟。比赛电脑需预先排练。
