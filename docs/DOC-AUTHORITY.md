## 0. 一句话规则

**「唯一事实源」只能在它真正管辖的范围内成立。** 排期归排期、出包归出包、产品归产品、工单归工单；跨语境的权威声明一律视为无效声明。

历史上出现过的冲突（现已裁定）：`Mochi-总体方案.md:4` 自称「唯一事实源」，而同一文件 `:619` 又指向 `MOCHI-URGENT-REPLAN`。这**不是文档写错**，是**授权范围没有写清**。本文件补上范围。

## 5. 元数据规范（新建 / 修订文档必须带）

```markdown
> **status**: draft | active | superseded | archived
> **last_verified**: YYYY-MM-DD

```

- `status: superseded` 的文件**必须**在头部写明替代者。
- `last_verified` 是**最后一次有人真的核对过内容与实际是否一致**的日期，不是文件修改日期。
- 全仓此前的自查结论：**「最后更新」字段零命中**。本规范是对该结论的收口。

## 7. 文档漂移自查

```bash
node scripts/scan-doc-drift.mjs          # 人读格式，带 文件:行号
node scripts/scan-doc-drift.mjs --json   # 机器可读
node scripts/check-skill-tools.mjs       # 技能/文档层工具名守卫（点号 + 不存在名），退出码 1 = 有问题
node scripts/check-snapshot-manifest.mjs # 出包快照清单 vs 磁盘（2026-09-12 实测 11 文件漂移，出包前必须收敛为 0）
```

11 条规则覆盖：权威声明 / 截止日期 / 内核版本 / 插件计数 / 点号工具名 / 手工热修 / 模型与公司名 / 预设口径 / 双界面口径 / 学生端口径 / 状态字段。

> **两个脚本的分工**：
> `scan-doc-drift.mjs` 是**取证**（把所有可疑处列出来给人看，只报告不阻断）；
> `check-skill-tools.mjs` 是**门禁**（只查工具名这一类硬错误，命中即退出码 1，已接 CI）。
