# Mochi 0.2.0

本次发布汇总 0.1.0 之后的产品更新，提供 macOS Apple 芯片版和 Windows x64 版。历史 v0.1.0 Release 与安装器继续保留。

## 主要更新

- 升级到固定的 Harness 0.2.0-rc.2 与 Electron 44 运行时，更新模型配置、推理设置、会话迁移和侧栏适配。
- 增加摄像头／展台拍题、语音输入与语音对话入口；教室端加入课堂助手、唤醒监听和课表规划。
- 增加可管理的记忆、日记、用户称呼与节日问候，教师与教室配置按角色隔离。
- 更新透明桌宠、思考与团队动效、纸面控件和品牌图标，完善窗口关闭、桌宠保留、权限提示与启动诊断。
- 完善教师和教室之间的局域网发现、配对、预约与消息处理，以及课件教学计划、文档和表格工具。
- 将教材转换为可按需使用的技能；教材内容及个人运行数据不随公开源码和安装器发布。

## 安装

- macOS Apple 芯片：下载 `Mochi-0.2.0-mac-arm64.dmg`，打开后将 Mochi 复制到“应用程序”再启动。
- Windows 10／11 x64：下载 `Mochi-Setup-0.2.0-win-x64.exe`，按安装向导操作。
- 公开安装包不携带开发者的长期 API Key。首次使用时配置自己的模型服务凭据；校园功能仍需相应校园账号和授权。
- 本版未签名、未公证，系统可能显示来源提示。校验文件与安装器同时提供。

原生构建、安装后启动及资源完整性结果由发布台账记录；自动化验证不代表所有学校设备的麦克风、摄像头、扬声器与网络均已现场验收。
